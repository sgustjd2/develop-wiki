## 개요
Docusaurus는 Meta가 만든 문서 사이트 생성기로, `docs/`의 Markdown/MDX를 사이드바가 있는 문서로, `blog/`를 블로그로 빌드한다. 문서 버전 관리(versioning)와 i18n이 내장되어 있고, MDX로 React 컴포넌트를 문서 안에 넣을 수 있다. 이 문서는 **3.10** 기준(npm `@docusaurus/core` latest 3.10.2, MIT, Node.js 20 이상). v4는 canary 단계다.

- 대안: Vue 기반 [VitePress](/develop-wiki/devtools/docs/vitepress/), Astro 기반 [Starlight](/develop-wiki/devtools/docs/starlight/), Python 생태계는 [Material for MkDocs](/develop-wiki/devtools/docs/mkdocs-material/).

## 설치
```bash
npx create-docusaurus@latest my-docs classic --typescript
cd my-docs
npm run start     # http://localhost:3000
npm run build     # build/ 에 정적 파일
```

## 핵심 개념
| 개념 | 설명 |
| --- | --- |
| `docusaurus.config.ts` | 사이트 제목·URL·`baseUrl`·프리셋·테마 설정 |
| preset-classic | docs·blog·pages 플러그인과 기본 테마 묶음 |
| `sidebars.ts` | 문서 사이드바 구성. `autogenerated`로 폴더 구조 자동 반영 |
| front matter | 문서별 `id`, `title`, `sidebar_position`, `slug` |
| MDX | Markdown 안에서 JSX·import 사용 |
| Admonitions | `:::tip`, `:::warning` 등 강조 블록 |
| Versioning | `docs:version` 명령으로 현재 문서를 버전 스냅샷 |
| Swizzling | 테마 컴포넌트를 꺼내 직접 수정 |

## 기본 사용법
`docs/intro.md`:

```md
---
sidebar_position: 1
title: 시작하기
---

# 시작하기

:::tip
설치 전에 Node.js 20 이상인지 확인하세요.
:::
```

`docusaurus.config.ts` 일부:

```ts
const config = {
  title: 'My Docs',
  url: 'https://example.github.io',
  baseUrl: '/my-docs/',
  i18n: { defaultLocale: 'ko', locales: ['ko', 'en'] },
  presets: [['classic', { docs: { sidebarPath: './sidebars.ts' }, blog: false }]],
};
export default config;
```

## 자주 쓰는 패턴
- **버전 문서.** 릴리스 때 `npm run docusaurus docs:version 1.0`으로 `versioned_docs/` 스냅샷을 만들고, `docs/`는 다음 버전 작업용으로.
- **검색.** Algolia DocSearch 설정 또는 로컬 검색 플러그인을 추가.
- **다이어그램.** `@docusaurus/theme-mermaid`로 [Mermaid](/develop-wiki/devtools/docs/mermaid/) 코드 블록 렌더링.
- **GitHub Pages 배포.** `url`·`baseUrl`을 맞추고 GitHub Actions로 `build/`를 배포.

## 언제 쓰나 / 피할 때
- 쓸 때: React에 익숙한 팀의 제품 문서, 여러 버전·언어 문서를 유지해야 할 때.
- 피할 때(대안): 빌드 속도와 가벼운 설정이 우선이면 VitePress·Starlight. 비 JS 팀이면 Material for MkDocs. UI 컴포넌트 사용 예·props 문서는 Storybook의 Docs(Autodocs) 기능이 더 맞다.
