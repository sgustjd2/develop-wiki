## 개요
Open Source Society University(OSSU)가 관리하는 커리큘럼으로, 학부 컴퓨터공학 학위 요건에 맞춰 **MIT, Harvard, Princeton 등 대학의 공개 강의를 순서대로 배치**했다. 과목마다 기간·주당 시간·선수 과목이 표로 정리돼 있다. 2026-11 기준 별 약 21.1만, 라이선스 MIT. 커밋은 많지 않지만 이어진다(최근 6개월 7건, 마지막 2026-11-09).

## 무엇이 들어 있나
| 단계 | 내용 |
| --- | --- |
| Prerequisites | 고교 수학(대수·기하·미적분 준비) 전제, 필요 시 사전 수학 과정 |
| Intro CS | 입문 프로그래밍 과목으로 공부를 계속할지 확인 |
| Core CS | 프로그래밍, 수학(이산수학·미적분·선형대수 등), CS 도구, 시스템(컴퓨터 구조·OS·네트워크), 이론(알고리즘), 보안, 응용(DB·ML·그래픽·소프트웨어 공학), 윤리 |
| Advanced CS | 고급 프로그래밍·시스템·이론·보안·수학 선택 과목 |
| Final project | 배운 것을 종합한 프로젝트 |
| How to show your progress | 진도 공유 방법 (README 가 진도용 스프레드시트를 제공) |

## 이렇게 활용하라
1. **Intro CS 부터 시작한다.** 이 과목이 맞지 않으면 다른 입문 자료로 바꿀 수 있다.
2. **Core CS 는 표의 순서와 선수 과목을 지킨다.** 각 과목의 "Prerequisites" 열을 확인한다.
3. **진도표를 만든다.** README 가 권하는 방식대로 스프레드시트·GitHub 저장소로 과목별 진척을 기록한다.
4. **커뮤니티를 쓴다.** Discord 에서 같은 과목을 듣는 사람과 스터디를 꾸릴 수 있다.
5. **과목 내용을 이 사이트 노트로 정리한다.** 예: OS 과목은 [프로세스·스레드](/develop-wiki/knowledge/cs-fundamentals/process-thread/), [CPU 스케줄링](/develop-wiki/knowledge/cs-fundamentals/cpu-scheduling/), 네트워크 과목은 [TCP vs UDP](/develop-wiki/knowledge/cs-fundamentals/tcp-vs-udp/) 와 함께 본다.

## 주의
- 전부 마치려면 주 20시간 기준 약 2년이 걸린다는 안내가 있다. 실무 취업 준비용으로는 범위가 넓다.
- 일부 강의는 플랫폼(Coursera·edX) 정책에 따라 무료 수강 범위가 바뀐다.
- 강의 대부분이 영어다. 한국어 번역은 없다.
