> 출처 메모: Stachowiak & Uludag 의 SIGGRAPH 2015 Advances 발표 슬라이드("Stochastic Screen-Space Reflections", EA Frostbite/DICE, PPTX 92장의 텍스트)를 읽었다. 슬라이드라 수식 유도·정확한 구현 코드가 없고 결과 영상·이미지는 보지 못했다. 발표자 노트는 읽지 못했다. 인용된 참고 논문(Valient 2014 Killzone, Uludag 2014 GPU Pro 5, Karis 2014 등)은 열람하지 않았다. 반사 폴백 체계는 [반사 프로브와 SSR 노트](/develop-wiki/knowledge/graphics-xr/reflection-probes-ssr/)에 있다. 아래 실험은 직접 만든 1차원 모형이다.

## 문제

기본 SSR(화면 공간 반사)은 거울 반사만 흉내 낸다. 법선 방향으로 광선을 쏘아 깊이를 따라가 맞은 곳의 색을 가져온다. 그러면 **거친 표면의 흐릿한 반사, 접촉 경화(물체에 닿을수록 선명), 늘어남(specular elongation), 픽셀별 법선·거칠기** 를 처리하지 못한다. 발표가 제시한 요구는 이 네 가지다. 기존 방식은 한계가 있었다. 사전 흐림 이미지 체인에서 거칠기로 밉을 고르는 방식(Killzone Shadow Fall)은 접촉 경화가 없고, 콘 트레이싱(Hi-Z cone tracing)은 복잡한 표면을 추적하지 못한다고 발표가 정리한다.

## 해법

핵심은 SSR 을 **몬테카를로 적분** 으로 보는 것이다. 이 알고리즘은 여섯 단계로 나뉜다(슬라이드의 분해): 타일 분류, 광선 할당, 저렴한 추적, 고품질 추적, 색 리졸브, 시간 필터.

### 1. BRDF 중요도 샘플링

픽셀의 거칠기·법선에 맞는 GGX 분포에서 반사 방향을 뽑는다. 저불일치 Halton 수열을 쓰고, 표면 아래로 들어가는 광선은 다시 생성한다. 가시 법선 분포(Heitz 2014)를 쓰면 더 낫겠다는 언급이 있다. 꼬리가 길어 생기는 노이즈를 줄이려고 **샘플을 거울 방향 쪽으로 치우치게(bias)** 한다. 이때 PDF 값은 정확해야 해서 잘린 분포의 정규화 상수가 달라지는데, 뒤의 재정규화가 이를 흡수한다고 한다.

### 2. 이웃 광선 재사용(희소 레이 트레이싱)

반해상도로 광선을 쏘고, 풀해상도 리졸브에서 **주변 픽셀들이 쏜 광선의 교차점을 재사용** 한다. 이웃의 광선도 내 BRDF 로 보면 유용한 방향일 가능성이 높고, 가시성은 같다고 가정한다(근사). 가중치는 `내 BRDF(교차점) / 원래 PDF` 다. 픽셀마다 이웃 광선의 서로 다른 혼합이 나오므로 픽셀별 법선·거칠기가 유지된다.

중요한 장치는 **가중치 정규화** 다. 슬라이드의 의사코드를 풀어 쓰면:

```ts
type Hit = { color: number; pdf: number; brdfAtThisPixel: number };

/** 이웃 광선 재사용 리졸브: Σ(색 × w) / Σ w, w = 내 BRDF / 원 PDF */
export function resolve(hits: Hit[]): number {
  let sum = 0, wsum = 0;
  for (const h of hits) { const w = h.brdfAtThisPixel / h.pdf; sum += h.color * w; wsum += w; }
  return sum / wsum;
}
```

슬라이드는 정규화가 없으면 이웃마다 BRDF 가 크게 다를 때 BRDF/PDF 비가 치솟아 "재사용하지 않는 것보다 나쁜" 결과가 나왔고, 정규화로 해결했다고 한다. 이는 한쪽(BRDF 사전 적분)을 해석적으로 빼고 나머지만 몬테카를로로 푸는 분산 감소로 설명된다.

직접 확인: 이 효과를 1차원에서 자체 정규화 중요도 샘플링으로 재현했다. 현재 픽셀의 BRDF 는 σ=0.1 가우시안 로브, 이웃은 중심을 `N(0, 0.1)` 에서 뽑고 σ=0.15 의 자기 분포로 광선을 쏜다. 장면은 0.05 에서 계단 모양으로 바뀐다(참값 0.5085). 각 설정 4000회 반복했다.

| 샘플 수 | 정규화 없음 RMSE | 정규화 RMSE |
| --- | --- | --- |
| 1 | 0.811 | 0.494 |
| 4 | 0.359 | 0.283 |
| 16 | 0.192 | 0.146 |

샘플 1개일 때 정규화는 약간의 편향(0.08)을 대가로 RMSE 를 39% 줄이고, 샘플이 늘면 편향은 사라진다. 3차원 BRDF 와 실제 장면이 아니므로 크기는 참고만 한다.

### 3. 광선 종류: 타일 분류와 계층 추적

- **타일 분류**: 화면을 타일로 나누고 1/8 해상도로 시험 광선을 쏴서 타일마다 "아무 것이나 맞는가", 맞은 값의 지각적 분산을 어림해 **광선 수를 사용자 최솟값~최댓값 사이에서 배분** 한다.
- **저렴한 광선**(거친 표면): 단순 선형 행진, 얇은 물체를 놓칠 수 있다.
- **고급 광선**(매끈한 표면): 깊이의 min-Z 피라미드를 **스택 없이** 걷는 계층 추적(Hi-Z). 현재 칸을 통과한 뒤 광선이 깊이 평면 위에 있으면 더 거친 레벨로 올라가고, 아래로 내려가면 더 세밀한 레벨로 내려가며 레벨 0 아래까지 내려가면 교차로 본다(슬라이드의 의사코드).
- 성능 측정 구성에서는 "Disney" 거칠기 20% 미만에만 고급 광선을 썼다.

### 4. 리졸브: 필터링된 중요도 샘플링

교차점의 색을 가져올 때 **미리 필터링한 이미지 피라미드** 의 밉을 고른다. 콘을 실제로 추적하지는 않고, 거칠기·교차점까지 거리·늘어남으로 발자국을 어림해 밉을 정한다(슬라이드는 로그 형태의 맞춤 함수를 썼다고만 한다). 샘플링 편향(위의 거울 쪽 치우침)과 같은 매개변수로 필터 편향을 줘서 같은 모양을 유지하면서 더 작은 밉을 읽어 성능과 공간 일관성을 높인다. 네 픽셀을 한꺼번에 리졸브하면서 밉 두 장만 읽고 보간하는 최적화도 설명한다. 거의 평평한 각도에서 콘이 너무 넓게 번지는 문제는 접선을 줄이는 임시 맞춤식으로 완화했다.

### 5. 시간 필터

반사 방향을 반영한 재투영을 쓴다. 단순히 표면 깊이로 재투영하면 반사가 끌려 번지므로 **반사 지점의 깊이** 를 더해 시차를 맞춘다(주변 광선 평균 사용). 이웃 색 클램프는 TAA 와 비슷하게 하되 번짐을 허용하고 노이즈를 줄이는 쪽으로 튜닝했다. 리졸브 때 2x2 로 재사용하면 2x2 노이즈 패턴이 생겨 TAA 가 "특징" 으로 오인하므로 대상 픽셀을 흩고 시간에 따라 지터한다. 사전 적분한 FG 항은 시간 필터 뒤에 곱해 번짐과 노이즈를 줄였다. [TAA 노트](/develop-wiki/knowledge/graphics-xr/taa-temporal-filtering-ao-ssr/)의 히스토리 클램프와 같은 원리다.

## 성능(슬라이드 수치)

PS4(Frostbite 테스트베드), 1600×900, 모든 픽셀이 반사적일 때 총 시간이다. 모든 패스는 컴퓨트이고 비동기로 돌릴 수 있다.

| 리졸브 샘플 | 반해상도 픽셀당 광선 | 유효 샘플/픽셀 | 총합(슬라이드) |
| --- | --- | --- | --- |
| 4 | 1 | 4 | 2.19 ms |
| 4 | 2 | 8 | 3.34 ms |
| 1 | 4 | 4 | 4.41 ms |

항목별 시간을 더하면 각각 2.08, 3.25, 3.98 ms 로 표의 총합과 맞지 않는다. 표에 담기지 않은 항목이 있는 듯하나 확인하지 못했다. 표에서 읽으면, 같은 유효 샘플 4개라도 광선을 적게 쏘고 리졸브 샘플을 늘리는 쪽(2.19 ms)이 광선을 많이 쏘는 쪽(4.41 ms)의 절반 정도다.

## 언제 쓰나

- 거칠기가 다양한 표면(젖은 도로, 금속, 바닥)의 화면 내 반사를 일관된 방식으로 얻고 싶을 때. 화면 밖 정보는 프로브·RT 폴백이 필요하다(슬라이드의 폴백 on/off 비교 참조).
- 레이 트레이싱 하드웨어가 없는 플랫폼에서 [레이 트레이싱 반사](/develop-wiki/knowledge/graphics-xr/hw-ray-traced-shadows-reflections/)의 개념(중요도 샘플링 + 디노이즈)을 빌리고 싶을 때.

## 주의/비용

- **화면 밖·가려진 면은 없다.** 폴백 없이는 반사 누락이 보인다.
- **작고 밝은 하이라이트는 여전히 노이즈를 남긴다.** 발표 결론이 인정하는 한계이며, 적응형 다중 중요도 샘플링이나 분산 추적 후 블러를 향후 과제로 든다.
- **이웃 가시성은 같다고 가정한다.** 근사이므로 가장자리에서 틀릴 수 있다.
- **시간 필터 의존.** 반사 색은 이전 프레임에서 오므로 지연이 완전히 사라지지 않는다. 클램프를 번짐 쪽으로 튜닝한다는 선택이 곧 흐려짐이다.
- **튜닝 대상이 많다.** 샘플링·필터 편향, 광선 할당 범위, 고급 광선 임계값, 리졸브 샘플 수.
- **다중 중요도 샘플링으로 이웃을 엄밀히 합치면 정확하지만 비싸다**(ALU·VGPR 부담, 슬라이드 보너스).
- 비교 대상 중 Killzone 식 사전 흐림은 가장 저렴하나 접촉 경화가 없다.
