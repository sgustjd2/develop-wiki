> 출처 메모: 원전 N. Epain, C. T. Jin, F. Zotter, "Ambisonic Decoding With Constant Angular Spread", *Acta Acustica united with Acustica* 100(5), 2014, pp. 928–936, DOI 10.3813/AAA.918772 를 EAA 디지털 아카이브(DAEL)에서 내려받아 **전문(요약·1~6장·부록)** 을 읽었다. 서지는 Crossref 조회와 논문 표지·첫 쪽으로 확인했다. 그림 값은 이미지라 읽지 못했고, 본문에 적힌 수치만 옮겼다. Zotter·Frank, *Ambisonics*(Springer 2019, CC BY 4.0)의 3.2절에서 이 논문을 가리키는 서술도 대조했다. 아래 계산 표는 내가 직접 계산한 것이다.

## 문제

[앰비소닉스](/develop-wiki/knowledge/graphics-xr/ambisonics-sound-field/) 디코더는 스피커 배치가 고르지 않으면 패닝 방향에 따라 성질이 변한다. 원전은 디코더가 갖췄으면 하는 성질을 셋으로 둔다.

- a) 스피커 에너지 `E(Ω) = Σ gᵢ²` 가 방향과 무관하게 일정
- b) 에너지 벡터 `rE` 의 방향이 목표 방향과 일치 (`rE` 방향 오차 최소)
- c) **각 퍼짐(angular spread)이 방향과 무관하게 일정**

a, b 는 [EPAD](/develop-wiki/knowledge/graphics-xr/epad-energy-preserving-ambisonic-decoding/)·[AllRAD](/develop-wiki/knowledge/graphics-xr/ambisonics-speaker-decoders-maxre-allrad/) 같은 앞선 방법이 다뤘다. 원전의 지적은 그런 방법도 **불규칙 배치에서는 `‖rE‖` 가 방향마다 달라져 퍼짐이 변한다**는 것이다. 원전은 퍼짐을 일정하게 하는 문제가 자신이 아는 한 기존 문헌에서 다뤄지지 않았다고 적는다.

### 퍼짐의 정의 (원전 식 11, 부록)

`rE = Σ eᵢ xᵢ / Σ eᵢ` (eᵢ = gᵢ², xᵢ = 스피커 단위 벡터)의 길이로 폭을 정한다. 연속 음원이 구면 위 원뿔(캡) 안에 균일하게 퍼져 있다고 보고 부록에서 `‖rE‖ = (1 + cos(σ/2)) / 2` 를 유도한 뒤 뒤집어

`σ = 2·arccos(2‖rE‖ − 1)`

을 퍼짐으로 쓴다. 스피커 하나만 켜지면 `‖rE‖ = 1`, σ = 0 이고, `‖rE‖ = 0` 이면 σ = 2π 다. 원전은 이 정의가 Frank 의 박사논문(2013)의 것과 약간 다르다고 밝힌다. 퍼짐은 스피커 신호 사이의 상관과 무관하게 정의되어 폭의 거친 예측 변수일 뿐이라고도 적는다.

**기존 노트와 정의가 다르다.** [EPAD 노트](/develop-wiki/knowledge/graphics-xr/epad-energy-preserving-ambisonic-decoding/)와 Zotter·Frank 책이 쓰는 폭은 `2·arccos‖rE‖` 다. 같은 `‖rE‖` 에서 숫자가 다르다.

| `‖rE‖` | `2·arccos‖rE‖` (책·EPAD 노트) | `2·arccos(2‖rE‖−1)` (이 논문 식 11) |
| --- | --- | --- |
| 1.00 | 0° | 0° |
| 0.924 (= cos 22.5°) | 45.0° | 64.1° |
| 0.866 | 60.0° | 85.9° |
| 0 | 180° | 360° |

(위 표는 두 식에 대입한 직접 계산이다.) 둘 다 `‖rE‖` 의 단조 감소 함수라서 "`‖rE‖` 를 일정하게" 하는 목표는 같지만, 각도로 읽은 값은 서로 바꿔 쓸 수 없다.

## 해법

원전은 두 단계로 푼다. 먼저 원하는 성질을 가진 **패닝 이득**을 만들고, 그다음 그 이득에 가장 가까운 **디코더 행렬**을 구한다.

### 1. VBIP 의 한계 (원전 3장)

VBIP(Vector-Base Intensity Panning)는 방향을 감싸는 스피커 셋(3D 에서 3개)의 **에너지**를 `ρ = X⁻¹_uvw x_S` 로 구해 합이 1이 되게 정규화한다. 에너지 합이 1이고 `rE` 방향이 목표와 정확히 일치한다(원전이 식으로 보인다). 그러나 `‖rE‖ = 1/(ρu+ρv+ρw)` 라서 스피커 방향에서는 1(퍼짐 0), 스피커에서 먼 방향에서는 작아진다. 원전의 CARLab 32채널 배치에서 VBIP 퍼짐은 스피커 방향의 0 에서 남북극의 약 92° 까지 변한다. VBIP 는 이미 가장 적은 스피커를 쓰므로 퍼짐을 이보다 **작게** 만들 수는 없고, 키울 수만 있다. 이 점이 아래 목표값 선택에 쓰인다.

### 2. MDIP: 보조 방향의 VBIP 에너지를 가중합 (원전 4장)

[MDAP](/develop-wiki/knowledge/graphics-xr/mdap-vbip-multiple-direction-panning/)의 아이디어를 VBIP 에 적용한다. 목표 방향 `Ω_S` 둘레에 보조 방향 `Ω_Sj` P 개를 두고

- 에너지: `ě_i(Ω_S) = Σ_j γ_j · ẽ_i(Ω_Sj)` (ẽ 는 VBIP 에너지)
- 총 에너지 1 로 정규화한 뒤 이득은 제곱근을 취한다.
- `rE` 가 목표 방향을 가리키려면 (a) 보조 방향이 목표 둘레에 대칭이고, (b) 가중치가 각거리에만 의존하고, (c) 보조 VBIP 의 `‖rE‖` 가 같아야 한다. VBIP 는 (c)를 어기므로 가중치를 `γ_j = w_α(Ω_S, Ω_Sj) / ‖r̃E(Ω_Sj)‖` 로 두어 보정한다. 이러면 보조 방향이 대칭일 때 `rE` 방향이 정확히 목표와 맞는다고 원전이 보인다.
- `w_α` 는 구경(aperture) α 의 Tukey 창이다. 각거리가 α/2 안이면 1, α 밖이면 0, 사이는 `cos²` 로 줄어든다.

```ts
// 원전 식 19–20 의 가중치 (보조 방향 j 하나에 대해). angle 은 목표와 보조 방향의 각거리(rad).
function tukey(angle: number, alpha: number): number {
  if (angle < alpha / 2) return 1;
  if (angle > alpha) return 0;
  return Math.cos(Math.PI * (angle / alpha - 0.5)) ** 2;
}
// rENormAux: 보조 방향의 VBIP 에너지 벡터 길이 ‖r̃E‖
const gamma = (angle: number, alpha: number, rENormAux: number) =>
  tukey(angle, alpha) / rENormAux;
```

원하는 퍼짐은 **방향마다 구경 α 를 따로 찾아** 얻는다. 절차는 (1) 목표 둘레의 동심 고리 위에 조밀한 보조 방향 집합을 만들고, (2) `‖ř_E‖` 가 원하는 값이 되도록 α 를 비선형 탐색(원전은 MATLAB `fminsearch`·`fzero` 류)으로 구하고, (3) 에너지를 정규화해 이득을 낸다. CARLab 배치에서 목표 퍼짐은 VBIP 의 최대값인 92° 로 고정했고(퍼짐을 VBIP 보다 줄일 수 없으므로), 구에 고르게 놓인 2562 방향에서 에너지 일정·`rE` 방향 오차 0·퍼짐 92° 를 얻었다고 보고한다.

### 3. 최소제곱 디코더 (원전 5장)

각 방향의 MDIP 이득을 열로 쌓은 `K`(스피커 × Q 방향)와 구면조화 행렬 `Y` 에 대해, 디코더가 만드는 패닝 이득 `G = D·Y` 를 `K` 에 맞춘다.

`D_CS = argmin_D ‖K − D·Y‖_F  =  K·Yᵀ·(Y·Yᵀ)⁻¹`

닫힌 해(유사역행렬)이며, 가상 음원 수 Q 는 구면조화 개수보다 커야 한다. 경험칙으로 구면조화 개수의 약 2배를 권하고, 위치는 Lebedev 격자나 구면 T-디자인을 예로 든다. 원전은 어떤 차수·불규칙 배치에도 적용된다는 점을 장점으로 든다.

### 4. 원전 결과 (CARLab 32채널, 2562 방향, 목표 퍼짐 92°)

원전 본문에 적힌 수치다(그림 값은 읽지 못했다).

- 차수 4: 에너지 변동 0.1 dB 안팎, `rE` 방향 오차는 모든 방향에서 1.5° 미만, 퍼짐은 목표 92° 둘레 ±3° 정도. 스피커가 촘촘한 적도 근처에서 퍼짐이 약간 작고, 드문 극 근처에서 약간 크다.
- 차수 1~10 전체: 에너지는 −0.1~0.15 dB 로 1 dB 의 JND 보다 훨씬 작다. `rE` 방향 오차는 차수가 오를수록 줄어 4차 이상에서 최대값이 JND(1°) 범위에 든다고 원전이 쓴다.
- 퍼짐: 1·2차는 목표 92° 보다 훨씬 크지만 방향에 대해서는 거의 일정하다(앰비소닉스 해상도 한계). 그보다 높은 차수는 원전이 대체로 JND(약 6°) 범위 안이라고 쓴다. 원전은 JND 를 10°로 표시한 곳과 6°로 쓴 곳이 있어 값이 문헌마다 다르다.
- 원전은 MDIP 이득의 지향 패턴이 넓어서 구면조화로 맞추기 쉽고, 좁은 VBIP 이득은 맞추기 어렵다고 설명한다.

### 직접 계산: 2D 링에서 방향별 퍼짐

원전은 3D 이므로 재현이 아니라 **2D 단순 모형**이다(폭 열은 3D 구면 캡에서 유도한 식 11 을 2D 값에 그대로 대입한 환산이라 상대 비교용이다). 스피커 8대 링에서 패닝 방향 1° 간격 360개, 에너지 가중 `rE`, 위 원전 식으로 폭을 읽었다. MDIP 는 2D 에 맞춰 보조 방향을 목표 둘레의 호(±α, 61점) 위에 두고, 가중치 `w_α/‖r̃E‖` 와 α 이분 탐색(24회)으로 `‖rE‖` 를 목표에 맞췄다. 목표는 VBIP 의 `‖rE‖` 최솟값이다. 디코더는 원형 조화(`[1, √2 cos mφ, √2 sin mφ]`)로 위 최소제곱 식을 풀었다. 이것은 내 2D 변형이며 원전의 구현이 아니다.

배치 A: 0°, 45°, …, 315° (균등). 배치 B: 0°, 25°, 50°, 75°, 120°, 180°, 240°, 300° (간격 25~60°).

| 배치·방법 | 에너지 범위 | `rE` 방향 오차 평균 / 최대 | `‖rE‖` 최소~최대 | 폭 `2·arccos(2‖rE‖−1)` |
| --- | --- | --- | --- | --- |
| A, VBIP | 0 dB | 0° | 0.924 ~ 1.000 | 0° ~ 64.0° |
| A, 최소제곱 N=3 | 0.00 dB | 0.00° / 0.00° | 0.920 ~ 0.920 | 65.9° 고정 |
| A, EPAD+max-rE N=3 | 0.00 dB | 0.00° / 0.00° | 0.924 ~ 0.924 | 64.1° 고정 |
| B, VBIP | 0 dB | 0° | 0.866 ~ 1.000 | 0° ~ 85.9° |
| B, 최소제곱 N=3 | 0.21 dB | 0.83° / 2.52° | 0.857 ~ 0.883 | 80.1° ~ 89.0° |
| B, 최소제곱 N=5 | 0.28 dB | 0.57° / 1.69° | 0.861 ~ 0.873 | 83.7° ~ 87.7° |
| B, EPAD+max-rE N=3 | 0.00 dB | 3.04° / 8.22° | 0.773 ~ 0.979 | 33.2° ~ 113.9° |

- 균등 링(A)은 대칭 덕에 어느 방법이나 퍼짐이 일정하다. **퍼짐이 문제가 되는 것은 불규칙 배치(B)** 다. B 의 VBIP 는 60° 간격의 한가운데에서 `‖rE‖ = cos 30° = 0.866` 으로 가장 작고(식으로도 확인), 25° 간격 구간에서는 1 에 가깝다.
- B 의 EPAD+max-rE(N=3, 스피커 8 ≥ 2N+1 = 7)는 에너지 변동이 0 인 대신 `‖rE‖` 가 0.773~0.979 로 퍼져 폭이 방향마다 크게 달라졌다. 같은 배치의 최소제곱 MDIP 피팅은 에너지를 0.2 dB 정도 흔드는 대신 폭 변동이 10° 안쪽으로 줄었다.
- 이 2D 결과는 "원전 방법이 방향별 폭 변동을 줄인다"는 원전 주장의 방향과 일치하지만, 크기는 배치·차수·보조 방향 수에 의존하는 내 설정의 결과다.

## 언제 쓰나

- 스피커 배치가 불규칙하고(돔, 비대칭 룸, 반구에 몇 대 빠진 설비) 음원이 움직일 때, **방향에 따라 음상이 좁아졌다 넓어졌다 하는 것**이 거슬리는 경우.
- 앰비소닉스 디코더 행렬을 오프라인으로 만들어 설치해 두는 설비. 계산은 한 번이고 재생 중에는 행렬 곱뿐이다.
- 원전이 장점으로 명시한 것은 임의 차수·임의 불규칙 배치에 적용된다는 점이다(p.929). 32채널 배치에서 10차(구면조화 121개)까지 계산한 예가 있어 필자가 보기에 스피커 수 ≥ `(N+1)²` 조건 없이 쓸 수 있다(원전이 이 점을 명시하지는 않으며, 숫자는 내가 센 것이다).

## 주의/비용

- **퍼짐을 줄이는 방법이 아니다.** 퍼짐은 VBIP 의 값보다 작아질 수 없어서 목표값을 방향 중 **가장 넓은 곳**에 맞춘다. 원전 결론도 일정함의 대가로 스피커가 촘촘한 영역의 퍼짐이 커진다고 적는다. 고른 배치일수록 선택할 수 있는 상수 퍼짐의 범위가 넓다.
- **오프라인 계산.** 방향마다 창 구경 α 를 비선형 탐색으로 찾으므로 실시간 제어가 안 된다. 원전은 재생 중 퍼짐을 바꾸려면 여러 퍼짐 값의 디코더를 미리 만들어 보간하는 방법을 가능성으로만 제시한다(구현·검증은 없음).
- **저차수의 한계.** 1~2차에서는 해상도가 모자라 목표 퍼짐보다 훨씬 넓어진다. 일정하긴 해도 좁은 음상은 못 낸다.
- **지각 검증이 없다.** 원전은 기준이 주로 에너지 벡터의 성질에 기반하고, 퍼짐이 지각 폭과 상관 있다는 근거는 Frank 의 수평면 실험이며 이 논문의 방법 자체의 지각 평가는 후속 연구로 미뤘다고 밝힌다. 3D 에서의 타당성은 미확인이다. 에너지 벡터는 스피커 신호의 위상을 무시한다.
- **에너지가 완전히 일정하지는 않다.** 위 최소제곱은 에너지를 직접 제약하지 않고 `K` 에 맞출 뿐이라 원전 수치로 0.1 dB 안팎, 내 2D 계산에서 0.2~0.3 dB 변동이 남았다. 에너지를 엄밀히 고정하는 쪽은 EPAD 다.
- **max-rE 같은 별도 가중은 필요 없다.** 퍼짐 목표가 `‖rE‖` 를 이미 정하므로 바깥에서 곱하는 차수별 가중과 역할이 겹친다(이 절은 내 해석이다).

## 비교

| 구분 | EPAD | AllRAD | 일정 각 퍼짐(이 논문) |
| --- | --- | --- | --- |
| 일정하게 하는 것 | 에너지(엄밀, `DᵀD = I`) | 직접 제약 없음(약간 변동) | 퍼짐 `‖rE‖` (+ 에너지 거의 일정) |
| 방법 | `Y` 의 SVD 에서 특이값을 1로 | 균일한 가상 스피커로 디코딩 후 VBAP | 방향별 MDIP 이득을 최소제곱으로 피팅 |
| 스피커 수 조건 | `L ≥ (N+1)²` (반구는 완화) | 사실상 없음 | 없음(원전 예: 32채널로 10차까지; 필자 추정) |
| 폭 변동 | 불규칙 배치에서 남음 | 남음 | 목표 |
| 계산 | SVD 1회 | VBAP + 변환 | 방향별 최적화(오프라인) + 유사역행렬 |

EPAD 와 이 논문을 "에너지 일정 대 퍼짐 일정"의 양자택일로 읽으면 부정확하다. 원전의 초록과 결과는 **에너지·방향 오차는 앞선 방법 수준으로 유지하면서 퍼짐을 추가로 일정하게** 한다고 주장한다. 다만 에너지는 근사로만 일정하고(0.1 dB 대), 엄밀한 에너지 일정은 EPAD 가 보장한다. 원전 서지에서 EPAD 는 이전 연구([7]), AllRAD 는 [8]로 인용된다.

## 검증 범위

- 읽은 것: Epain·Jin·Zotter 2014 전문 텍스트(요약, 1~6장, 부록, 참고문헌). Zotter·Frank 책의 3.2절 해당 문단(원전 [7] 인용)과 폭 척도 `2·arccos‖rE‖` 서술(2.3.1절 "Model of the Perceived Width").
- 서지: Crossref·OpenAlex 조회와 논문 첫 쪽(표지 포함)이 일치 — Acta Acustica united with Acustica, vol. 100, no. 5, pp. 928–936, 2014-09, DOI 10.3813/AAA.918772. 접수 2014-05-21, 채택 2014-07-14.
- 직접 계산: 위 2D 표 두 개(Python·NumPy). 원전 3D 결과의 재현이 아니며 MDIP 의 2D 변형·구현 세부(보조 점 수, 탐색 횟수)는 내 설정이다.
- 미확인: 원전 그림 1~5 의 값(배치 좌표 포함), CARLab 32채널의 정확한 스피커 각도, 원전 이후의 지각 평가·청취 실험, 후속 구현(툴박스 등)의 존재, 원전이 JND 를 10°·6° 두 가지로 쓴 이유, 책이 이 논문을 "각 방향 가상 음원의 방향·가중 최적화"로 요약한 것과 원전 MDIP(창 구경 α 최적화)의 정확한 대응.
