"Fortschritte der Akustik AIA-DAGA 2013, Merano" 라는 서지는 요청받은 정보이며 PDF 로는 확인하지 못했다. **AllRAD 원전(Zotter·Frank, JAES 60(10), 2012)은 읽지 못했고**, AllRAD 의 설명은 이 논문이 요약한 범위로 한정한다. 아래 계산 표는 내가 직접 계산한 것이다.

## 문제

[앰비소닉스](/develop-wiki/knowledge/graphics-xr/ambisonics-sound-field/) 디코더는 스피커가 불규칙하면 패닝 방향마다 음량, 방향 사상, 음상 폭이 흔들린다. 논문 서두는 앞선 두 방법, [EPAD](/develop-wiki/knowledge/graphics-xr/epad-energy-preserving-ambisonic-decoding/)(에너지 보존)와 [AllRAD](/develop-wiki/knowledge/graphics-xr/ambisonics-speaker-decoders-maxre-allrad/)(전방위)가 어느 쪽이 나은지, 고전적 샘플링·모드매칭 디코더와 비교하면 어떤지를 묻고, 하나의 예시 배치로 답을 훑는다. 결론은 "EPAD 는 우수하지만 복잡하고, AllRAD 와 SAD 를 합친 AllRAD+ 는 에너지 변동이 EPAD 에 견줄 만하며 방향 사상은 AllRAD 를 닮는다"이다.

## 해법

### 비교 대상 (논문 식 1~8, 17)

원형(2D) 조화 `yN(φ)` 는 `1/√(2π)`, `cos(nφ)/√π`, `sin(nφ)/√π`(|n| ≤ N)다. 패닝 방향 `θs` 의 가상 음원은 `εN = diag{aN}·yN(θs)`(식 2)이고 스피커 신호는 `x = D·χN`(식 4), 따라서 패닝 이득은 `g(θs) = D·εN(θs)`(식 9)다. `aN` 은 부엽을 줄이는 max-rE 가중이며 원형에서는 `an = cos(n·90°/(N+1))` 로 적는다(논문은 이 가중을 원래 디코딩 쪽에 두는 관행과 동등하다고 덧붙인다).

| 디코더 | 식 | 논문의 설명 |
| --- | --- | --- |
| SAD | `D = (π/L)·YNᵀ` (반원, 식 6) | 스피커 방향에서 조화를 샘플링. `t ≥ 2N+1` 인 t-디자인에서 최적(원형에서는 `2N+2` 각형 이상의 정다각형). |
| MMAD | `D = YNᵀ(YN·YNᵀ + αI)⁻¹` (식 17) | 모드를 맞춘다. 반원에서 `α = 0` 이면 불안정(그림 5). |
| EPAD | `V̌_{:,1:N+1}·Ǔᵀ·U_{:,1:N+1}ᵀ` (식 8) | 반원 전용 변형: 구간을 조금 넓혀(±105°, 1° 간격) 조화의 SVD 를 하고 `N+1` 개 기저로 줄인 뒤, 줄인 스피커 인코딩을 한 번 더 SVD 해 특이값을 버린다. |
| AllRAD | `G_{1:L,:}·D_SAD^(opt)` (식 7) | 균일한 가상 스피커(예: 정 50각형)에서 최적 SAD 를 쓰고 VBAP 행렬 `G` 로 실제 스피커에 옮긴다. 불완전 배치에서는 (L+1)번째 가상 더미 스피커로 빈 방향의 신호 손실을 다룬다. |
| AllRAD+ | `gAllRAD·D_AllRAD + gSAD·D_SAD` (식 13) | AllRAD 와 SAD 의 가중합. |

MMAD 정칙화는 `α = (1/4)·(L/π)` 를 예로 든다(식 17 아래, 그림 6 캡션). 논문은 "스피커 하나가 맡는 평균 각 구간의 역수에 알맞은 스칼라를 곱한 값"이라고 설명한다. 스피커 9개이면 `α = 9/(4π) ≈ 0.72` 다(이 수치는 위 식에 대입한 내 계산).

### 지표 (식 10~12)

- 에너지: `Ê(φs) = Σ gl²(φs)`
- 에너지 벡터: `r̂E(φs) = Σ gl²(φs)·θl / Ê(φs)`
- 방향 오차: `ε̂E(φs) = [arctan(r̂E,y / r̂E,x) − φs + 180°]_{mod 360°} − 180°`
- 폭: `σ̂E(φs) = 2·arccos ‖r̂E(φs)‖`

세 지표 모두 이상적으로는 패닝 방향에 무관해야 하고, 예시 배치는 이상적이지 않아서 방향에 따라 변한다고 논문이 적는다.

**폭 정의 대조.** 식 12 의 `2·arccos‖rE‖` 는 [EPAD 노트](/develop-wiki/knowledge/graphics-xr/epad-energy-preserving-ambisonic-decoding/)가 쓰는 정의와 같다. [일정 각 퍼짐 노트](/develop-wiki/knowledge/graphics-xr/ambisonic-decoding-constant-angular-spread/)의 환산표 기준으로 보면, 같은 `‖rE‖` 에서 Epain 2014 의 `2·arccos(2‖rE‖−1)` 와 값이 다르다(예: `‖rE‖ = 0.866` 에서 60° 대 85.9°). 이 논문의 폭 그래프를 Epain 논문의 퍼짐 그래프와 각도로 직접 비교하면 안 된다.

### 예시 설정

반원 불규칙 스피커 9개: −90°, −60°, −44°, −25°, −5°, 30°, 50°, 65°, 90°. 차수 N = 2, 4, 8, 12 를 그림 1~4 에 그리고, 비교 기준으로 VBAP 를 함께 그린다. 이 VBAP 는 180° 더미 스피커를 두고 **비정규화 이득의 제곱근**을 써서 패닝 범위에서 `ε̂E = 0` 이 되도록 한 변형이다. 그림 2~4 의 `Ê` 는 −90°~90° 평균으로 정규화했다.

### 논문의 결과 서술 (그림 1~6)

논문은 결과를 곡선 그림과 짧은 서술로 낸다. 그림 값은 서술 외에는 숫자로 적히지 않았고, 아래는 서술과 그림에서 읽은 경향이다.

- **EPAD**(그림 1): 패닝 범위 −90°~90° 에서 `Ê` 가 완전히 일정. 오차는 매끄럽지만 ±90° 경계에서 소리가 안쪽으로 끌린다. 폭은 가장 큰 간격(−5°~30°)에서만 출렁인다. 이 배치에서 N = 8 까지만 동작한다(그림 1 캡션).
- **SAD**(그림 2): 스피커 간격이 큰 곳에서 음량이 떨어지고, 그곳에서 방향 오차가 크게 넘친다(overshoot). 폭은 대체로 매끄럽다.
- **AllRAD**(그림 3): `Ê` 변동이 거칠어 보인다. 반면 방향 오차는 매우 매끄럽고 작으며 ±90° 경계에서도 그렇다. 폭은 모든 디코더 중 출렁임과 오버슈트가 가장 적고 패닝 범위 밖에서는 오히려 줄어든다고 평한다.
- **MMAD**: `α = 0` 이면 다른 디코더와 경쟁이 안 된다(그림 5). `α = L/(4π)` 로 정칙화하면 경쟁할 만해진다(그림 6).

### AllRAD+ 의 계수 (식 13~14)

논문의 논리는 이렇다. 균일 가상 배치에서 AllRAD 는 에너지가 일정하지만, VBAP 단계에서 스피커 쌍마다 가상 음원이 **에너지가 아니라 선형으로** 겹쳐 더해져서 간격이 큰 곳의 에너지가 커지고 촘촘한 곳은 줄어든다. 논문은 대략 큰 간격에서 AllRAD 가 에너지를 두 배로, 촘촘한 곳에서 절반으로 만든다고 적는다. SAD 는 반대로 큰 간격에서 에너지를 잃고 촘촘한 곳에서 대략 두 배가 된다. 두 경향을 진폭으로 옮긴 연립방정식이 식 (14)다.

```
[ √2    0  ] [ gAllRAD ]   [ 1 ]
[ 1/√2  √2 ] [ gSAD    ] = [ 1 ]
```

풀면 `gAllRAD = 1/√2`, `gSAD = 1/√8` 이다(PDF 3쪽 식 (14)로 확인). 검산하면 첫 줄에서 `√2·gAllRAD = 1`, 둘째 줄에서 `(1/√2)(1/√2) + √2·gSAD = 1/2 + √2·gSAD = 1` 이므로 `gSAD = 1/(2√2) = 1/√8` 이다. 논문은 이 방정식을 "estimated equation system" 이라고 부른다. 즉 최적화가 아니라 어림이다.

```ts
// AllRAD+ (식 13): 같은 크기의 행렬 두 개의 가중합. 행렬은 L×(2N+1).
const gA = 1 / Math.SQRT2, gS = 1 / Math.sqrt(8);
const allradPlus = (dAllrad: number[][], dSad: number[][]) =>
  dAllrad.map((row, l) => row.map((v, k) => gA * v + gS * dSad[l][k]));
```

논문은 그림 4 에서 `Ê` 가 개선되고, `ε̂E`·`σ̂E` 에서는 AllRAD 의 좋은 특성이 대체로 유지된다고 쓴다. 에너지 개선을 논하는 문장은 N ≤ 8 에 한정된다.

### MVLAD: AllRAD 와 같은 "가장 VBAP 다운" 디코더 (부록, 식 15~16)

논문은 Nicolas Epain 이 학회(AIA-DAGA)에서 제안한 관점이라고 밝힌다. 디코더 `D` 의 l번째 스피커 행을 `dlᵀ` 라 하자. 앰비소닉스 이득 `yN(θs)ᵀ·dl` 이 VBAP 이득 `gl^(v)(θs)` 에 가장 가깝도록, 모든 패닝 방향에 걸친 제곱 오차를 스피커마다 최소화한다(식 15).

1. 적분을 S 개 방향 샘플의 합으로 바꾼다: `‖YNᵀ·dl − gl^(V)‖² → min`, 여기서 `YN = [yN(θ1)…yN(θS)]`.
2. 최소제곱해: `dl = (YN·YNᵀ)⁻¹·YN·gl^(V)`.
3. 모든 스피커를 쌓고 전치: **`D_MVLAD = G·YNᵀ(YN·YNᵀ)⁻¹`** (식 16).
4. 샘플링이 원 또는 구를 균일하게 덮으면 `YNᵀ(YN·YNᵀ)⁻¹ ≈ (2π 또는 4π)/S · YNᵀ`. 이때 식 16 은 식 7(AllRAD)과 같아진다.

`YNᵀ(YN·YNᵀ)⁻¹` 는 "보통 잘 행동하는 모드매칭 디코더"이며 샘플링이 촘촘하고 균일할 때 그렇다고 논문이 단서를 단다. 샘플 방향을 AllRAD 의 가상 스피커 방향과 같게 잡고 `G` 도 같은 VBAP 행렬로 두는 것이 전제다(논문은 `G` 를 양쪽에 같은 기호로 쓴다).

이 논문은 Epain 의 2014 논문 [일정 각 퍼짐 디코딩](/develop-wiki/knowledge/graphics-xr/ambisonic-decoding-constant-angular-spread/)을 인용하지 않고(참고문헌 7편에 없다), MVLAD 와 그 방법의 관계를 말하지 않는다. 같은 저자 이름이 나올 뿐이며, 둘의 구조가 비슷해 보이는 점(방향 샘플에 맞춘 최소제곱, `K·Yᵀ(YYᵀ)⁻¹` 꼴)은 내 관찰이다.

### 직접 계산: 반원 9개 스피커 2D 재현

설정은 위 논문 그대로다(9개 스피커, N = 2·4·8·12, 원형 조화, max-rE 가중, 패닝 방향 0.5° 간격 −90°~90°, `Ê` 는 구간 평균으로 정규화). 구현은 numpy 로 내가 짰고 **논문의 그림을 재현한 것이 아니라 서술을 검증한 2D 구현**이다.

- AllRAD: 균일 정 50각형 가상 스피커, `D = G·(2π/50)·Yᵀ`, VBAP 는 2D 쌍 방식 + 180° 더미(행 제거). **`G` 는 에너지 정규화 VBAP 를 썼다.** 논문의 AllRAD 의 `G` 정규화는 이 4쪽에 명시되어 있지 않으므로 구현 차이일 수 있다.
- EPAD: 식 8 을 그대로 구현. AllRAD+: `D_AllRAD/√2 + D_SAD/√8`. MMAD: `α = L/(4π)`.

범위 ±80° 안에서 읽은 값이다(경계의 끌림을 뺀 값).

논문 서술과 비교한 결과다.

- **재현됨.** EPAD 는 N = 4, 8 에서 에너지가 거의 일정(0.24 dB, 0.03 dB; N = 2 는 0.59 dB)이고, N = 12 는 스피커 9개 < N+1 = 13 이라 에너지가 무너진다(그림 1 캡션의 "N = 8 까지"와 같은 방향). SAD 는 가장 넓은 간격(−5°~30°)에서 에너지가 떨어지고(N = 8 에서 12.5° 부근 −4.2 dB), 그 구간에서 방향 오차가 가장 크게 나온다(N = 8, 최대 9.1°). AllRAD 는 방향 오차가 SAD·EPAD 보다 작고(N = 4, 8, 12) 에너지 변동은 1~2 dB 대, 패닝 범위 밖(105°~150°)에서는 N = 8 에서 폭이 0.8~1.5° 로 줄어(범위 밖에서는 사실상 한 스피커로만 소리가 나는 구조적 결과) "범위 밖에서 폭이 줄어든다"는 서술과 맞는다. MMAD 는 `α = 0` 이면 N = 4 에서 22 dB 변동으로 불안정하고, `α = L/(4π)` 로 정칙화하면 1 dB 대로 안정된다.
- **일부 재현.** AllRAD+ 는 N = 2, 4, 8 에서 AllRAD 의 에너지 변동을 절반 안팎으로 줄였다(예: N = 8, 1.66 → 0.67 dB). 다만 EPAD(0.03 dB)만큼 평평하지는 않아 "EPAD 와 견줄 만하다"는 서술은 이 2D 구현에서는 약하게만 맞는다. 방향 오차는 N = 2, 4 에서 줄고 N = 8 에서 늘었으며(2.7° → 4.5°) 같은 자릿수라 "대체로 유지"로 읽을 수 있다. N = 12 에서는 AllRAD+ 가 AllRAD 보다 에너지 변동이 크다(2.78 대 1.45 dB). 논문의 에너지 개선 문장이 N ≤ 8 을 전제로 하는 점과 같은 방향이다.
- **재현되지 않음.** 식 14 의 "큰 간격에서 AllRAD 가 에너지를 대략 두 배, 촘촘한 곳에서 절반" 추정은 내 구현에서 확인되지 않았다. 평균 대비 AllRAD 에너지는 큰 간격(12.5°)에서 1.14~1.18배, 촘촘한 곳(−34.5°, 57.5°)에서 0.82~0.87배였다. 방향(큰 간격에서 커짐)은 맞지만 크기는 훨씬 작다. SAD 는 큰 간격 0.38~0.76배, 촘촘한 곳 1.2~1.4배로 방향은 맞다. `G` 정규화가 다르면 크기가 달라질 수 있어 구현 차이일 가능성이 있다.
- **계수의 최적성.** SAD 비중을 `gSAD/gAllRAD` 0~1.5 로 훑으면 에너지 변동이 가장 작은 비율은 N = 2, 4 에서 약 1.4~1.5, N = 8 에서 0.45, N = 12 에서 0.15 였다. 논문의 비율 0.5 는 N = 8 에서만 최적에 가깝다. 논문이 "어림"이라 한 것과 일치하며, 차수·배치에 따라 최적 비율이 달라지는 것으로 보인다(내 구현의 결과). 또한 내 구현에서 두 디코더의 평균 에너지 크기가 달라서 "합이 1이 된다"는 식 14 의 절대 정규화는 확인하지 못했고, 위 표는 `Ê` 를 평균으로 정규화한 상대 변동이다.
- **MVLAD = AllRAD.** `D = G·Yᵀ(YYᵀ)⁻¹` 를 AllRAD 의 가상 배치와 같은 균일 샘플(S = 26, 50)에서 계산하면 `D_AllRAD` 와 최대 오차 2e−15(수치 정밀도 수준)로 일치했다(S = 50 은 N = 2~12, S = 26 은 N = 4·12 에서 확인). 샘플을 한쪽으로 몰아(S = 70, 앞쪽 반원 60 + 뒤 10) 불균일하게 하면 `G·(2π/S)·Yᵀ` 와 최대 0.33(최대 원소 약 0.57)로 크게 어긋나서, "균일 샘플링일 때만 같다"는 논문의 조건이 실제로 필요함을 확인했다. 이 경우 MVLAD 쪽이 AllRAD 꼴보다 방향 오차가 작았다(N = 4, 최대 3.9° 대 12.4°). 한 가지 배치·한 가지 몰림의 결과다.

충실도: 2D 반원이고 논문도 2D 반원이라 설정은 같다. 그러나 `G` 의 정규화, VBAP 변형, 그림의 정확한 곡선은 논문 그림과 대조하지 못했다. 위 표는 서술의 경향을 검증하는 용도다.

## 언제 쓰나

- 스피커가 불규칙하고 N 이 중간(≤ 스피커 수 정도)일 때 AllRAD 를 쓰되, 에너지 변동이 거슬리면 SAD 와 가중합(AllRAD+)을 시도해 볼 수 있다. 계수는 그림 4 가 쓴 1/√2·1/√8 이 출발점이고, 차수에 따라 조정이 필요할 수 있다(내 계산).
- AllRAD 를 구현할 때 가상 스피커 배치 대신 방향 샘플 + VBAP 행렬 + 의사역행렬로 쓰고 싶다면 MVLAD 식(식 16)을 쓸 수 있다. 샘플이 균일하면 같은 결과다.
- 스피커 수가 충분하고(이 예에서는 9개로 N = 8 까지; `L ≥ N+1` 은 내 추정) 에너지 일정성이 최우선이면 EPAD.

## 주의/비용

- **4쪽 단신이라 증거가 얇다.** 결과는 스피커 9개짜리 반원 한 배치의 그림이고, 청취 실험이 없으며, 지표는 에너지 벡터 기반 추정값이다. 일반 결론으로 옮기기 어렵다.
- **AllRAD+ 계수는 어림값이다.** 논문 스스로 "estimated". 내 2D 구현에서는 차수별 최적 비율이 달랐고, N = 12 에서는 AllRAD 보다 나빠졌다.
- **에너지는 EPAD 만큼 일정하지 않다.** 논문은 "EPAD 에 견줄 만하다(competitive)"라고 쓴다.
- **EPAD 는 복잡하고 스피커 수 제한이 있다.** 논문은 EPAD 를 "우수하지만 복잡하다"고 부른다. 이 예에서 N = 8 까지만 동작.
- **MVLAD 동치는 조건부.** 균일 샘플링 근사 `YNᵀ(YN·YNᵀ)⁻¹ ≈ (2π/S)·YNᵀ` 가 성립할 때만 AllRAD 와 같다. 식 16 의 `YN·YNᵀ` 가 특이하면 불안정하다(샘플 부족, 비균일).
- **3D 는 다루지 않는다.** 예시와 계산은 반원이고 3D 는 식 형태만 같을 뿐 검증이 없다.

## 검증 범위

- 읽은 것: 논문 PDF 4쪽 전체(본문, 식 1~17, 부록 2개, 참고문헌 7편). 식 (14) 계수는 PDF 3쪽 이미지로 확인(`1/√2`, `1/√8`). `α = L/(4π)` 도 PDF 4쪽 이미지로 확인. 그림 1~6 은 이미지로 보았으나 곡선의 수치를 읽은 것은 아니며 경향만 서술에 반영했다.
- 직접 계산: 위 2D 반원 구현(numpy). `G` 에너지 정규화 선택, 가상 정 50각형, VBAP 더미 180°는 내 구현 설정이다.
- 미확인: AllRAD 원전 JAES 2012 본문(읽지 못함), 논문의 AllRAD `G` 정규화 세부, 그림의 정확한 수치, 학회명·연도·개최지(PDF 에 표기 없음), 참고문헌 원문(Daniel 2001, Gerzon 1992, Poletti 2000, Malham·Myatt 1995, Pulkki 1997 은 열어 보지 않음), MVLAD 를 다룬 Epain 의 문헌 존재 여부, 논문 이후의 청취 평가.
