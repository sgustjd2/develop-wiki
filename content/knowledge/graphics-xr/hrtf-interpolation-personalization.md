> 출처 메모: Arend 외 "Magnitude-Corrected and Time-Aligned Interpolation of HRTFs"(arXiv 2303.09966 사전본)의 서론·방법·평가 설정과 Guezenoc & Séguier "HRTF Individualization: A Survey"(arXiv 2003.06183, 4쪽 요약판)를 읽었다. 시간 정렬 방법의 원전(SUpDEq, 온셋 기반, 위상 보정)과 SH 보간의 수식 논문, 개인화 개별 논문들(Middlebrooks, Zotkin, Hu 등)은 읽지 못했고 두 논문의 서술을 통해서만 옮긴다. 지각 평가 수치는 두 문서가 인용하는 대로이며 직접 검증하지 않았다. 아래 수치 실험은 직접 만든 모형이다. 두 논문은 모두 심사 전 또는 요약판이라 최종판과 다를 수 있다.

## 문제

[HRTF 바이노럴 렌더링](/develop-wiki/knowledge/graphics-xr/hrtf-binaural-rendering/)은 방향별 HRIR 쌍을 합성곱한다. 두 가지 문제가 남는다.

1. **보간**: 측정은 시간이 걸려 방향 수가 제한되는데, 머리를 돌릴 때 매끄러운 렌더링에는 1~2° 해상도(논문이 최소 가청 각도를 근거로 제시)가 필요하다. 구면 전체를 1°·2° 간격으로 덮으려면 면적만으로 약 41,000·10,300 방향(구면적 41,253 제곱도 기준 직접 계산)이 된다.
2. **개인화**: 남의 머리로 잰 HRTF 는 외재화 약화, 고도 오판, 앞뒤 혼동을 낳는다(서베이 서두).

## 해법 1: 시간 정렬 보간

방향이 조금만 바뀌어도 HRTF 의 위상과 크기가 크게 변한다. 논문은 빠른 위상 변화의 주된 원인을 이렇게 설명한다. 좌표 원점이 두 귀의 중점이라 방향에 따라 귀까지의 거리가 달라지고, 이것이 방향마다 다른 **광대역 군지연** 으로 더해진다. 이 지연을 그대로 섞으면 안 된다.

표준 절차는 세 단계다.

1. **시간 정렬 `T`**: 방향마다 지연을 제거한다. 방법은 여럿이다. 논문이 쓴 SUpDEq 는 강체 구의 해석적 전달 함수로 나누고, 그 밖에 온셋(임계값 초과 첫 샘플) 기반 정렬과 위상 보정이 언급된다.
2. **보간 `I`**: 정렬된 HRTF 를 촘촘한 격자로 보간한다. 전역 방식으로 구면 조화(SH) 분해, PCA, 국소 방식으로 무게중심·자연 이웃·최근접·역거리 가중이 있다.
3. **역정렬 `T⁻¹`**: 새 방향의 지연을 되돌린다.

논문 서론에 따르면 시간 정렬은 어떤 보간법에도 도움이 되고 SH 보간에서는 지각적으로 투명한 보간에 필요한 방향 수가 **최대 3분의 1** 로 줄며, 방향 6개처럼 극단적으로 성긴 격자에서도 ITD(귀 사이 시간차)는 복원된다. 그러나 크기 응답, 특히 머리 그림자 쪽(반대편 귀)의 크기 오차가 남아 음색 변화를 만든다.

### 직접 확인

시간 지연 두 개가 다른 HRIR 을 단순 선형 보간하면 어떻게 되는지 확인했다. 샘플 40 과 70 에 펄스가 있는 두 HRIR(차이 30샘플, 48 kHz 에서 625 µs)을 가정하고 중간값을 만들었다.

- **단순 선형 보간**: 샘플 40 과 70 에 각각 진폭 0.5 인 **펄스 두 개** 가 남는다. 주파수 응답은 빗살 필터이고 첫 노치가 `fs/(2·30) = 800 Hz`, 실측으로 이 주파수에서 기준 대비 0.006 배, 8 kHz 아래 최대 -50 dB 까지 파인다.
- **시간 정렬 보간**(아래 TypeScript): 샘플 55 에 진폭 1.0 인 펄스 **하나**. 기준 대비 크기 변화 거의 0 dB.

```ts
/** 온셋(임계값 초과 첫 샘플) 기준 */
const onset = (h: number[], thr = 0.1) => { const m = Math.max(...h.map(Math.abs)); return h.findIndex((x) => Math.abs(x) >= thr * m); };
const shift = (h: number[], d: number) => h.map((_, i) => h[i - d] ?? 0);

/** 두 HRIR 사이를 t∈[0,1] 로 보간: 지연을 빼고 섞은 뒤 보간한 지연을 되돌린다 */
export function interpTimeAligned(a: number[], b: number[], t: number) {
  const da = onset(a), db = onset(b);
  const aa = shift(a, -da), bb = shift(b, -db);
  const mix = aa.map((x, i) => (1 - t) * x + t * bb[i]);
  return shift(mix, Math.round((1 - t) * da + t * db));
}
```

이 모형은 지연만 다른 이상적 펄스다. 실제 HRIR 은 귓바퀴 반사로 파형도 방향마다 다르므로 온셋 정렬은 근사에 그친다.

### 크기 보정(MCA)

논문의 기여는 시간 정렬 보간 뒤에 **크기 보정** 을 하나 더 붙인 것이다. 성긴 HRTF 와 보간 결과 둘을 41개 감마톤 필터(ERB 간격, 50 Hz~20 kHz)로 평활해 청각 해상도로 줄인 뒤, 평활본을 보간한 것(오차가 작다)을 기준으로 보간된 HRTF 의 크기를 맞추는 보정 필터를 만든다. 입력 외에 추가 정보가 필요 없고 시간 정렬·보간 방법과 조합할 수 있다. SH 보간은 공간 앨리어싱 주파수 `f_A = N·c/(2π·r0)`(N 은 SH 차수, c 음속, r0 머리 반지름) 이하에서만 물리적으로 맞으므로 보정은 그 아래에서 0 dB 로 두고 3분의 1옥타브 안전 구간에서 서서히 키운다. 머리 반지름을 8.75 cm 로 가정하고 직접 계산하면 `f_A` 는 N=1 에서 624 Hz, N=3 에서 1.87 kHz, N=15 에서 9.36 kHz 다. 이득 상한(소프트 리미터)을 둬서 보간 오류가 과도한 부스트가 되지 않게 한다.

평가는 HUTUBS 데이터베이스의 시뮬레이션 개인 HRTF 96개를 Lebedev 격자(1~15차, 6~350 방향)로 줄였다가 900점 Fliege 격자로 늘려 비교했다. 논문 초록의 결과는 매우 성긴 입력에서 고주파 크기 오차가 평균 최대 1.5 dB, 반대편(contralateral) 영역에서 최대 4 dB 줄어 ILD 가 개선된다는 것이다. 지각 청취 실험은 아니다(논문에서 지각 품질은 비공식 청취 언급에 그친다).

## 해법 2: 개인화

서베이는 방법을 네 갈래로 나눈다.

| 갈래 | 요점 | 보고된 한계·성과 |
| --- | --- | --- |
| 음향 측정 | 무향실에서 스피커 호와 턴테이블로 방향별 임펄스 응답을 잰다 | 장비 고가, 전통적으로 한 방향씩 재면 최대 1시간 45분(2014 구성), 인터리브 스윕으로 약 20분, 연속 회전 방식은 4분. 실제 음원과 정위 성능은 대체로 동등하다는 합의 |
| 수치 시뮬레이션 | 3D 스캔으로 FM-BEM, FDTD 등을 풀어 계산 | 귀 스캔이 머리·몸통보다 정밀해야 함. 계산은 수 시간. 소수 피험자(2~3명) 평가에서 좋은 결과 |
| 인체 치수 기반 | 적응(주파수 스케일링), 선택(데이터베이스 최근접), 회귀(PCA·신경망) | 스케일링은 개선되지만 자신의 HRTF 보다 못함(9~11명). 선택은 고도 점수 평균 15% 개선(CIPIC 7개 치수). 회귀 대부분은 지각 평가 없음 |
| 청취 피드백 | 사용자가 데이터베이스에서 고르거나 필터를 조정 | 선택 15분~35분 이상 소요, 본인 것보다 못하지만 일반 세트보다 나음 |

## 언제 쓰나

- 성긴 측정(예: 간이 시스템)으로 얻은 개인 HRTF 를 렌더링에 쓸 격자로 늘릴 때.
- 방향 전환 때 HRIR 을 바꾸면 클릭이 나므로 보간·크로스페이드가 필요한 실시간 렌더러. 이때 시간 정렬 없이 섞으면 빗살이 생긴다.
- 개인화는 외재화·고도 정위가 중요한 XR·음악 감상, 헤드트래킹을 같이 쓰는 제품에서 검토한다.

## 주의/비용

- **단순 보간은 빗살 필터를 만든다.** 위 실험처럼 지연 차이만큼 노치가 파인다. ITD 가 큰 측면에서 특히 심하다.
- **시간 정렬도 완전하지 않다.** ITD 는 복원되어도 크기 오차(반대편 음색·ILD)가 남아 MCA 같은 후처리가 나왔다. 온셋 기반 정렬은 온셋 검출 오류에 약하다.
- **SH 보간의 차수·주파수 한계.** 앨리어싱 주파수 위에서는 물리적으로 맞지 않는다.
- **개인화 평가가 빈약하다.** 서베이가 적은 대로 상당수 연구가 지각 실험이 없거나 피험자가 2~11명이다. 개선 폭의 일반화는 조심한다.
- **치수 기반 방법의 입력 오차.** 사용자가 직접 재거나 찍은 사진이 틀리면 결과도 틀린다(서베이 지적).
- **저고도 데이터.** 측정 HRTF 는 낮은 고도에서 누락·오류가 있어 논문은 시뮬레이션 데이터로 평가했다.
- **지각적으로 투명한 최소 방향 수**는 아직 연구 대상이다. 논문은 이를 더 줄이는 것을 목표로 한다고만 말한다.
