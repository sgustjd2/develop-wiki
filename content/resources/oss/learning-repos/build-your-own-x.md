## 개요
"What I cannot create, I do not understand" 라는 문구를 내건 목록으로, 익숙한 기술을 **직접 재구현하는 튜토리얼**을 주제별로 모았다. 각 링크에 구현 언어(C, Go, Python, Rust, JavaScript 등)가 붙어 있어 쓰고 싶은 언어로 고를 수 있다. Daniel Stefanovic 이 시작했고 지금은 CodeCrafters 가 관리한다. 2026-11 기준 별 약 56.4만으로 GitHub 최상위권이며, 라이선스는 CC0(README 표기). 최근 6개월 커밋 48건, 마지막 2026-11-18.

| --- | --- |
| 시스템 | Database, Docker, Git, Shell, Operating System, Memory Allocator, Network Stack, Processor |

## 이렇게 활용하라
1. **매일 쓰는 도구 하나를 고른다.** 예: Git 을 매일 쓴다면 "Build your own Git" 에서 언어가 맞는 튜토리얼을 연다.
2. **튜토리얼을 그대로 따라 친 뒤, 한 기능을 스스로 추가한다.** 예: 자작 셸에 파이프(`|`)나 리다이렉션을 붙여 본다.
3. **원본 구현과 비교한다.** 만든 뒤 실제 프로젝트의 해당 부분 코드를 읽으면 차이(에러 처리, 성능 고려)가 보인다.
4. **관련 지식 노트로 개념을 정리한다.** 예: Docker 를 만들었다면 [컨테이너 내부 구조](/develop-wiki/knowledge/cs-fundamentals/container-internals/), DB 를 만들었다면 [B-Tree](/develop-wiki/knowledge/algorithms/b-tree/) · [LSM Tree](/develop-wiki/knowledge/algorithms/lsm-tree/) 를 본다.
5. **테스트가 있는 단계별 과제를 원하면** 관리사인 CodeCrafters 의 유료 과정도 있지만, 목록 자체는 무료 외부 튜토리얼 링크다.

## 주의
- 링크된 튜토리얼은 외부 블로그·책이라 품질과 완결성이 제각각이고, 일부는 오래됐거나 미완성이다.
- README 상단 배너는 관리사(CodeCrafters) 홍보다.
- 한국어 번역은 없다.
