## 개요

- 통계 분석은 대부분 **모집단(population) 전체를 못 보기** 때문에 일부(표본, sample)만 보고 전체를 추정한다. 표본이 모집단을 대표하지 못하면 아무리 정교한 검정을 써도 결론이 틀린다.
- 표본을 어떻게 뽑았는지가 "어디까지 일반화할 수 있는가"를 정한다. 확률 표본은 각 개체가 뽑힐 확률을 알 수 있어 추론의 근거가 되고, 비확률 표본은 그렇지 않다.
- 변수의 **측정 척도**는 "그 값에 어떤 연산·통계량이 의미 있는가"를 정한다. 코딩된 숫자라고 평균을 내도 되는 것은 아니다.

## 시험 범위 대응

- 빅데이터분석기사 2과목 "통계기법 이해 – 기술통계: 데이터 요약·표본추출"에 대응한다. ADsP 데이터분석의 "통계학 개론"에도 같은 내용이 들어 있다(공식 출제범위 항목명 기준).

## 핵심 용어

| 한국어 | 영어 | 정의 |
| --- | --- | --- |
| 모집단 | population | 연구 질문이 가리키는 전체 대상 집단 |
| 표본 | sample | 실제로 자료를 수집한 모집단의 부분집합 |
| 전수조사 | census | 모집단의 모든 개체를 조사하는 것 |
| 단순임의추출 | simple random sampling | 모든 개체가 같은 확률로 뽑히고 한 개체의 선택이 다른 개체의 선택에 영향을 주지 않는 방법 |
| 층화추출 | stratified sampling | 모집단을 비슷한 개체끼리 층(strata)으로 나눈 뒤 각 층에서 (보통 무작위로) 뽑는 방법 |
| 군집추출 | cluster sampling | 모집단을 군집(cluster)으로 나누고 몇 개 군집을 무작위로 골라 그 안의 개체를 모두 조사하는 방법 |
| 다단계추출 | multistage sampling | 군집추출과 같되 선택된 군집 안에서도 일부만 무작위로 뽑는 방법 |
| 편의표본 | convenience sample | 접근하기 쉬운 개체를 골라 만든 표본 |
| 무응답 편향 | non-response bias | 무작위로 뽑힌 사람 중 많은 수가 응답하지 않아, 응답자가 모집단과 달라지는 편향 |

## 확률 표본추출

위 표의 네 방법은 OpenIntro *Introduction to Modern Statistics* 2판 2장에서 확인한 정의다. 계통추출은 해당 절에서 확인하지 못했다(아래 미확인).

| 방법 | 절차 | 잘 맞는 상황 | 비용·주의 |
| --- | --- | --- | --- |
| 단순임의 | 명부 전체에서 무작위로 n개 | 명부가 있고 집단이 비교적 균질 | 명부가 필요하다. 소수 집단이 우연히 빠질 수 있다 |
| 층화 | 층 구분 → 층마다 추출 | 층 간 차이는 크고 층 안은 비슷할 때 | 층 구분 변수를 미리 알아야 한다. 층별 비율을 맞춰 가중해야 할 수 있다 |
| 군집 | 군집 몇 개 선택 → 전수 | 개체가 지리적으로 흩어져 있어 조사 비용이 클 때 | OpenIntro 는 군집 안 변동이 크고 군집끼리 비슷할 때 도움이 된다고 한다. 반대로 군집 안이 서로 닮으면 같은 n 에서 정밀도가 떨어진다(설계효과 개념, 필자 설명) |
| 다단계 | 군집 선택 → 군집 안 부분 추출 | 전국 조사처럼 단계가 자연스러울 때 | 설계·가중 계산이 복잡하다 |
| 계통(systematic) | 시작점을 무작위로 정하고 k번째마다 추출 | 순서 있는 명부 | 필자 설명이며 이 절의 출처에서 확인하지 못했다. 명부 순서에 주기성이 있으면 편향될 수 있다 |

### 직접 계산: 층화가 정밀도를 높이는 경우

모집단 10,000명(층 A 7,000명 평균 50, 층 B 3,000명 평균 80, 층 내 표준편차 5)에서 n = 100 을 뽑는 시뮬레이션을 4,000번 반복했다(seed 42, 값은 seed 의존).

| 방법 | 표본평균들의 평균 | 표본평균들의 표준편차 |
| --- | --- | --- |
| 단순임의(n=100) | 59.06 | 1.49 |
| 비례 층화(A 70 + B 30) | 59.07 | 0.50 |
| 편의표본(B가 3배 쉽게 뽑힘) | 66.95 | 1.58 |

- 모집단 평균은 59.08. 두 확률 표본은 평균에 대해 치우침이 없고, 층 간 차이가 클 때 층화는 변동을 약 1/3 로 줄였다.
- 편의표본은 B 가 과대 대표되어 평균이 약 8 높게 나왔고, **표본이 커져도 이 편향은 사라지지 않는다**. 표본 크기를 늘리는 것은 우연 오차를 줄일 뿐 편향을 고치지 못한다.

## 표본 편향의 종류

| 편향 | 원인 | 예 |
| --- | --- | --- |
| 선택(편의) 편향 | 쉽게 닿는 사람만 포함 | 앱 사용자 설문을 전 국민 의견으로 일반화 |
| 무응답 편향 | 응답한 사람이 비응답자와 다름 | 불만이 큰 고객만 설문에 응답 |
| 자발적 응답 편향 | 스스로 참여한 사람만 포함 | 리뷰를 남기는 구매자만 집계 (출처의 온라인 평점 사례와 같은 구조) |
| 생존자 편향 | 살아남은 대상만 관찰 | 폐업한 가게가 빠진 업종 분석 (필자 예) |

비확률 표본(할당, 눈덩이, 판단 표본 등)은 탐색·예비 조사에서 쓰지만, 오차 범위를 확률적으로 계산할 근거가 없다. 할당·눈덩이·판단 표본의 정의는 이 노트에서 1차 출처로 확인하지 않았다.

## 측정 척도 4종

Stevens(1946)가 제안한 분류로 알려져 있다. 아래 표는 일반적으로 교과서에서 정리하는 형태이며, 원문은 열람하지 못했다(검증 범위 참고).

| 척도 | 영어 | 성질 | 예 | 의미 있는 통계량 |
| --- | --- | --- | --- | --- |
| 명목 | nominal | 구분만 가능, 순서 없음 | 혈액형, 성별, 지역 | 빈도, 최빈값, 카이제곱 계열 |
| 서열 | ordinal | 순서는 있으나 간격이 동일하다는 보장 없음 | 만족도 5단계, 학점 등급 | 위 + 중앙값, 분위수, 순위 상관(교과서 관행. Stevens 본문은 순위 상관이 등간을 요구한다고 지적) |
| 등간 | interval | 간격이 동일, 절대 영점 없음 | 섭씨 온도, 연도 | 위 + 평균, 표준편차, Pearson 상관 |
| 비율 | ratio | 간격 동일 + 절대 영점 | 키, 무게, 매출, 소요 시간 | 위 + 비율·배수 비교, 변동계수(Stevens Table 1). 기하평균은 교과서식 추가이며 Stevens 표에서 확인하지 못했다 |

- "30도가 15도의 두 배 따뜻하다"는 말이 틀린 이유: 섭씨는 영점이 임의라서 비율 비교가 안 된다. 켈빈은 비율 척도다.
- 척도는 위로 갈수록 아래 척도의 연산을 모두 포함한다.
- 질적(범주형) = 명목+서열, 양적(수치형) = 등간+비율로 묶어 부르기도 한다. 수험서마다 용어가 다를 수 있다.

### 헷갈리는 구분

| 쌍 | 구분 |
| --- | --- |
| 서열 vs 등간 | 리커트 5점 척도는 순서만 보장된다. 평균을 내는 관행이 흔하지만 간격이 같다는 가정이 필요하며, 이를 피하려면 중앙값·순위 기반 방법을 쓴다 |
| 등간 vs 비율 | 0 이 "없음"을 뜻하면 비율. 0 이 약속일 뿐이면 등간 |
| 이산형 vs 명목 | 이산/연속은 값의 형태, 명목/서열은 의미 구조다. 서로 다른 축이다 |

## 언제 쓰나 / 주의

- 조사 설계 단계: 명부 유무, 층·군집 구조, 예산을 보고 방법을 고른다. 확률 표본이 불가능하면 한계를 결론에 적는다.
- 분석 단계: 척도를 먼저 확인해 검정을 고른다. 서열 자료에 평균 기반 모수 검정을 쓰기 전에 [비모수 검정](/develop-wiki/knowledge/data-analytics/nonparametric-tests-rank-based/)을 검토한다.
- 표본이 크다는 이유로 편향을 무시하지 않는다. 시뮬레이션에서 보듯 편향은 n 과 무관하다.
- 층화·군집 설계 자료를 단순임의 표본처럼 분석하면 표준오차가 틀린다(설계에 맞는 가중·분산 추정이 필요). 상세 방법은 이 노트에서 다루지 않는다.

## 검증 범위

- OpenIntro *Introduction to Modern Statistics* 2판 2장(data-design 페이지)에서 모집단·표본·전수조사, 단순임의·층화·군집·다단계 추출, 편의표본, 무응답 편향의 정의를 읽었다. 같은 절에서 "자발적 응답 편향"이라는 용어는 확인하지 못했고 온라인 평점 사례만 확인했다.
- Stevens(1946) 원문(Science 103(2684), 677–680)은 팩트체크에서 미러 PDF 로 읽었다. 원문 Table 1 은 명목=최빈값·사례 수·분할 상관, 서열=중앙값·백분위수, 등간=평균·표준편차·순위 상관·적률 상관, 비율=변동계수다. 순위 상관을 서열 척도에 두는 것은 교과서 관행이며, Stevens 본문은 순위 상관이 등간 척도를 요구한다고 지적한다. 이 노트의 "허용 통계량" 표는 교과서식 정리라 Stevens 표와 배치가 다를 수 있다.
- 계통추출, 할당·눈덩이·판단 표본, 생존자 편향은 1차 출처로 확인하지 않았다(미확인).
- 시뮬레이션은 직접 실행했고 수치는 seed 42 기준이다.
