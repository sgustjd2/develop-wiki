## 문제

[ReSTIR](/develop-wiki/knowledge/graphics-xr/restir-reservoir-resampling/)는 이웃 픽셀이 찾은 좋은 표본을 내 픽셀에서 다시 쓰는 기법이다. 직접 조명(DI)에서는 표본이 "광원 위의 점" 이라 이웃 픽셀에서도 그대로 의미가 있다. 그런데 **간접광 경로 전체**를 재사용하면 이야기가 달라진다.

- 이웃 픽셀의 경로는 카메라에서 출발하는 첫 정점부터 다르다. 그 경로를 내 픽셀에서 "그대로" 쓸 수는 없고, 내 픽셀에서 시작하는 비슷한 경로로 **변환**해야 한다.
- 변환하면 표본의 확률 밀도가 바뀐다. 이것을 보정하지 않으면 결과가 편향된다.
- 논문은 ReSTIR GI(Ouyang 외 2021)가 첫 간접 정점에 재연결하는 방식을 암묵적으로 쓰지만 성능을 위해 정확성을 일부 포기했다고 평가한다. 각주에서는 재연결 정점을 램버트 반사로 가정하는 것을 편향 원인의 하나로 든다.

## 해법

### 1. 이동 사상의 정의 (4.3절, 7.1절)

- 픽셀 k 의 경로 x̄ 를 픽셀 j 의 경로 ȳ 로 보내는 함수 T 를 이동 사상이라 부른다. 원래 경로를 **기준 경로(base)**, 옮긴 경로를 **오프셋 경로(offset)** 라 한다.
- y0 은 센서 위, y1 은 픽셀 j 를 통과하는 광선의 첫 히트다. 설계의 자유도는 **y2 이후의 정점을 어떻게 정하느냐**에 있다.
- 목표는 두 가지다. 경로 기여가 비슷하게 유지될 것(f(T(x̄)) ≈ f(x̄)), 야코비안 행렬식이 1 에 가까울 것.
- 이동 사상은 **전단사(bijective)** 여야 한다. 다만 모든 경로가 정의역에 들 필요는 없다. 옮길 수 없는 경로에는 "정의되지 않음" 을 돌려주면 된다. 그 경로는 재사용 후보에서 빠진다(노이즈와 계산 낭비는 생기지만 편향은 아니다). 반대로 **역변환이 안 되는 이동을 허용하면 큰 편향**이 생긴다고 논문은 경고한다.

### 2. 재샘플링 가중치에 들어가는 야코비안 (4.1절)

일반화된 RIS 에서는 입력 표본 Xi 가 서로 다른 정의역(다른 픽셀)에서 와도 된다. 표본을 고를 때의 가중치는 대략 다음 꼴이다.

```
w_i = m_i(T_i(X_i)) · p̂(T_i(X_i)) · W_i · |∂T_i / ∂X_i|
```

- `p̂` 는 내 픽셀의 목표 함수(대개 경로 기여의 밝기), `W_i` 는 그 표본의 비편향 기여 가중치(PDF 의 역수를 대신하는 값, 이전 RIS 패스 결과도 됨), `m_i` 는 재샘플링 MIS 가중치다.
- 마지막 항이 이동으로 바뀐 밀도의 보정이다. 이 항을 빼면 옮긴 경로가 자기 픽셀의 밀도로 평가되어 편향이 생긴다.
- 논문은 수렴을 해치는 요인으로 야코비안이 **무한히 커질 수 있다**는 점을 명시하고(5.4절), 각 항을 따로 다루는 대신 표본 구성과 MIS 가중치 설계로 함께 묶어 해결한다.

### 3. 구성 요소 (7.2절)

| 구성 요소 | 하는 일 | 맞는 상황(논문 서술) |
| --- | --- | --- |
| 재연결(vertex copy) | 오프셋 경로를 기준 경로의 다음 정점에 바로 잇는다(`y_{i+1} = x_{i+1}`), 이후 정점은 복사 | 확산·거친 재질. 정점을 공유해 싸다 |
| 반벡터 복사 | 기준 경로의 반벡터를 국소 접공간에서 복사하고 반사·굴절 방향으로 다시 추적 | 거의 정반사인 정점 |
| 방향 복사 | 나가는 방향을 전역 좌표로 복사하고 다시 추적 | 환경 맵 |
| 랜덤 리플레이 | 기준 경로가 쓴 **난수**를 그대로 써서 같은 샘플링 방법으로 다시 추적 | 광택면. 대개 반벡터 복사와 비슷한 결정을 낸다 |
| 매니폴드 탐색 | 다음 연결 가능 정점을 복사하고 사이의 정반사 정점을 반복 계산 | 정반사 사슬. 비싸다 |

재연결의 함정으로 논문이 든 것: 고광택면의 이상 반사를 못 따라감, 가려진 곳을 지나 재연결, 재연결 구간 길이가 크게 바뀜, 다른 물체·재질 사이 이동, 반사·굴절로 경로가 너무 멀리 갈라짐.

### 4. ReSTIR PT 가 쓴 두 가지 이동 사상 (7.4~7.6절)

- **재연결 이동**: 항상 첫 간접 정점에서 잇는다(`y2 = x2`). 재연결 정점만 저장하고 경로 기여를 다시 평가하면 되므로 구현이 쉽다. 대부분 확산인 장면에 잘 맞는다.
- **하이브리드 이동**(Hua 외 2019 기반 개선): 연결 조건을 만족할 때까지 랜덤 리플레이로 재연결을 **미룬다**. 기준 경로가 연결 조건을 처음 만족하는 정점을 미리 하나만 골라 두고(재연결은 그 정점에서만 일어남), 그 정점만 저장한다. 오프셋 경로가 다른 정점을 가장 이른 재연결 지점으로 판정하면 역변환이 안 되므로 "정의되지 않음" 을 돌려준다.
- **연결 조건 두 가지(논문 제안)**
  - 거리 조건: 재연결 구간이 짧으면(모서리 근처) 기하 항이 특이점을 만들어 노이즈가 커진다. 구간 길이가 임계값 이상일 때만 재연결하고, 아니면 랜덤 리플레이로 미룬다. 대칭성 때문에 오프셋 쪽 구간에도 같은 검사를 한다.
  - 로브별 조건: 여러 로브를 합친 BSDF(확산층 + 클리어코트)는 거칠기 하나로 판정하면 모호하다. 그래서 **샘플링 때 고른 로브**의 거칠기만 본다. 이를 위해 경로에 로브 인덱스를 붙인 확장 경로 공간을 정의한다. NEE 로 샘플한 정점은 로브 중 하나라도 거칠면 거친 것으로, 광원 정점은 항상 거친 것으로 본다.
- 실시간 설정의 파라미터 예(8.3절): 로브별 GGX 거칠기 임계 0.2, 거리 임계는 장면 크기의 1~5 %. 저장소는 경로당 88바이트(재연결 정점과 리플레이용 시드 포함).

### 5. 야코비안 식 (8.1절)

이전 정점까지는 두 경로가 고정됐다고 보고 정점 하나씩의 야코비안을 구한다. 경로 전체는 **정점별 야코비안의 곱**이다.

- 재연결(입체각 매개변수): `(cos θ_y / cos θ_x) · (|x_{i+1} − x_i|² / |x_{i+1} − y_i|²)`. θ 는 각 경로가 재연결 정점에 도착하는 방향과 그 정점의 기하 법선 사이 각이다.
- 랜덤 리플레이(입체각): 두 경로가 다음 정점을 고를 때의 **입체각 샘플링 확률의 비**.
- 주 표본 공간(난수 공간)에서는 랜덤 리플레이의 야코비안이 항상 1 이고, 입체각 야코비안은 위의 확률 비로 나눠 바꿀 수 있다. 논문의 시제품은 구현이 쉬워 주 표본 공간을 썼다고 한다.

직접 계산해 보면 재연결 야코비안의 거리 항이 왜 위험한지 보인다. 두 코사인을 1 로 두고 기준 쪽 구간을 1 로 고정했을 때:

| 오프셋 쪽 구간 길이 | 거리 항 |
| --- | --- |
| 1 | 1 |
| 0.5 | 4 |
| 0.1 | 100 |
| 0.02 | 2,500 |

오프셋 정점이 재연결 정점에 붙을수록 값이 제곱으로 커진다. 거리 조건이 바로 이 경우를 랜덤 리플레이로 돌린다.

```ts
type V3 = [number, number, number];
const sub = (a: V3, b: V3): V3 => [a[0] - b[0], a[1] - b[1], a[2] - b[2]];
const len2 = (a: V3) => a[0] ** 2 + a[1] ** 2 + a[2] ** 2;
const dot = (a: V3, b: V3) => a[0] * b[0] + a[1] * b[1] + a[2] * b[2];

// 재연결 정점 x1 에서의 입체각 야코비안 (8.1절 식의 구조를 옮긴 내 예시)
function reconnectJacobian(x0: V3, y0: V3, x1: V3, n1: V3, dMin: number): number | null {
  const dx = sub(x0, x1), dy = sub(y0, x1);
  if (Math.sqrt(len2(dx)) < dMin || Math.sqrt(len2(dy)) < dMin) return null; // 짧은 구간 → 리플레이로 미룸
  const cosX = Math.abs(dot(dx, n1)) / Math.sqrt(len2(dx));
  const cosY = Math.abs(dot(dy, n1)) / Math.sqrt(len2(dy));
  return (cosY / cosX) * (len2(dx) / len2(dy));
}
```

`null` 은 "이 정점에서는 재연결하지 않음" 이며, 실제 구현에서는 대칭성을 지키도록 기준·오프셋 양쪽에서 같은 판정을 내야 한다.

## 언제 쓰나

- **재연결 이동**: 장면이 대부분 확산·거친 재질이고 비용이 중요할 때. 논문의 광택 코넬 박스 1 spp 비교에서 재연결 5 ms, 하이브리드 12 ms 였다(RTX 3090, 1920×1080).
- **하이브리드 이동**: 광택 상호 반사, 반사·굴절이 화면에서 중요할 때. 논문은 거친 면에서는 재연결과 비슷하게 동작하면서 광택면 노이즈를 줄였다고 보고한다.
- **로브별 판정**: 다층 재질이 많을 때. 논문 그림 12에서 로브 하나만 평가하는 쪽이 오차(MAPE 0.297 대 0.316)와 시간(38.7 ms 대 51.7 ms) 모두 나았다.

## 주의/비용

- **완벽한 이동 사상은 없다.** 논문은 장면과 하드웨어에 따라 최선이 달라진다고 말한다. 먼 하이라이트에 비친 커스틱은 하이브리드가 약하고(랜덤 리플레이 경로가 작은 하이라이트를 놓침), 가까운 접촉 커스틱은 재연결이 약하다(거의 델타인 BRDF 에서 재연결 실패).
- **메모리.** 하이브리드는 재연결 후보를 모두 저장하면 메모리 대역폭을 크게 쓴다. 논문은 후보를 하나로 고정해 줄였지만 그만큼 재사용 기회가 줄어든다.
- **파라미터 의존.** 거리 임계값은 장면 축척에 따라 바뀌고, 자동 설정은 논문의 향후 과제로 남았다.
- **화면 공간 재사용의 한계.** 아주 작은 기하나 날카로운 커스틱은 화면 공간에서 과소 표집되어 노이즈, 줄무늬, 얼룩이 남을 수 있다(논문 10.1절).
- **볼륨 미지원.** 시제품은 표면 간 수송만 다룬다. 매질에는 별도의 볼륨 이동 사상이 필요하다.
- **디노이저 입력은 별개 문제.** 재사용 경로의 히트 거리를 디노이저에 그대로 넘기면 안 된다. [hitT 계약](/develop-wiki/knowledge/graphics-xr/restir-gi-pt-hit-distance-contract/)과 [NRD 히트 거리 누적·PSR](/develop-wiki/knowledge/graphics-xr/nrd-hit-distance-accumulation-psr/)을 따로 본다.
- **두 시제품 모두 성능 최적화 전**이라고 논문이 밝힌다. 위 ms 수치는 상대 비교로만 읽는다.
