## 개요
Free Ebook Foundation 이 관리하는 목록으로, StackOverflow 의 "무료 프로그래밍 책" 질문에서 출발해 GitHub 로 옮겨졌다. 저자·출판사가 무료로 공개한 책과 강의만 싣는 것이 원칙이다. 자료의 **언어별 파일**(한국어 포함)과 주제별 파일이 따로 있다. 2026-11 기준 별 약 40.2만, 라이선스 CC-BY-4.0. 커밋이 매일 수준으로 이어진다(마지막 2026-11-12).

한국어 자료 목록(`books/free-programming-books-ko.md`, 2026-07 갱신)과 기여 방법·행동 강령의 한국어 번역(`docs/HOWTO-ko.md` 등)이 있어 `koreanDocs: true` 로 둔다. 다만 본문 README 자체의 한국어 번역은 아니다.

## 이렇게 활용하라
1. **검색 사이트에서 찾는다.** [검색 페이지](https://ebookfoundation.github.io/free-programming-books-search/)에서 제목·언어로 바로 찾을 수 있다.
2. **한국어 자료부터 보고 싶으면 한국어 파일을 연다.** `free-programming-books-ko.md` 에 한국어로 쓰인 무료 책·튜토리얼이 주제별로 있다.
3. **"Programming Languages" 목록에서 공식 무료 책을 고른다.** 예: Rust 의 The Rust Programming Language, Go 공식 문서처럼 언어 공식 자료가 먼저 나오는 경우가 많다.
4. **출판 연도와 대상 버전을 확인한다.** 오래된 판(예: Python 2, 구버전 프레임워크)이 섞여 있다.
5. **Problem Sets 로 연습을 붙인다.** 책 한 권을 읽은 뒤 해당 언어로 문제를 풀어 본다.

## 주의
- 링크가 많아 일부는 이동·삭제됐을 수 있다(정기적으로 링크 점검을 돌리지만 완벽하지 않다).
- "무료"의 범위가 자료마다 다르다(온라인 열람만 무료, 등록 필요 등).
