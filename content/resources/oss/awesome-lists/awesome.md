## 개요
Sindre Sorhus 가 관리하는 저장소로, 개별 링크가 아니라 **다른 awesome 리스트**를 분야별로 묶어 둔 인덱스다. "awesome-python", "awesome-go" 같은 이름 규칙과 배지, 리스트 작성 가이드(awesome-lint 검사)가 모두 이 저장소에서 시작됐다. GitHub 에서 별이 가장 많은 저장소 가운데 하나다(2026-11 기준 약 53.8만). 라이선스는 CC0-1.0.

2026-11 기준 archived 가 아니고 마지막 커밋은 2026-09 이다. 새 리스트 등록 PR 이 몇 달에 한 번씩 묶여 반영되는 속도라, 아주 최근 생긴 리스트는 아직 없을 수 있다.

## 이렇게 활용하라
1. **분야 섹션에서 리스트를 고른다.** 예를 들어 Go 를 시작한다면 Programming Languages → Go 로 들어가 [Awesome Go](/develop-wiki/oss/awesome-lists/awesome-go/) 를 연다.
2. **리스트 저장소의 활동부터 본다.** 들어간 리스트의 마지막 커밋 날짜와 열린 PR 수를 확인한다. 1~2년 이상 멈춘 리스트는 항목도 낡았을 가능성이 크다.
3. **리스트 안에서 다시 별 수·최근 커밋으로 거른다.** awesome 리스트에 있다고 해서 지금도 유지보수되는 라이브러리라는 뜻은 아니다.
4. **브라우저 페이지 내 검색(Ctrl/Cmd+F)을 적극 쓴다.** README 한 장에 수백 개 링크가 있어 키워드 검색이 가장 빠르다.
5. **직접 리스트를 만들 때는 가이드를 따른다.** contributing 문서의 요건과 `npx awesome-lint` 로 형식을 맞춘다.

## 주의
- 리스트를 모은 목록이라 품질은 하위 리스트마다 크게 다르다. 일부 하위 리스트는 오래 방치돼 있다.
- 대부분 영어 자료다. 한국어 번역은 없다.
- README 상단에 관리자의 다른 앱 홍보와 후원 영역이 있다. 본문 목록과는 무관하다.
