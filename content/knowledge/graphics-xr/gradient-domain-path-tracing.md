> 출처 메모: Kettunen·Manzi·Aittala·Lehtinen·Durand·Zwicker, "Gradient-Domain Path Tracing"(ACM TOG 34(4), SIGGRAPH 2015) 저자 사전 인쇄판 PDF(Aalto 프로젝트 페이지)를 텍스트로 추출해 1~7장 전체를 읽었다. **보충 자료(주파수 분석 유도, 야코비안 유도)와 공개 코드(Mitsuba 기반)는 보지 않았다.** 이동 사상이 ReSTIR 로 이어졌다는 서술은 GRIS(SIGGRAPH 2022) 관련 연구 절을 근거로 한다. 아래 수치는 논문 식 7 로 내가 직접 계산했다.

## 문제

경로 추적 이미지의 잡음은 대부분 **고주파**(픽셀 단위 얼룩)다. 각 픽셀은 서로 무관한 경로 묶음으로 추정되므로, 이웃 픽셀의 차이를 보면 잡음이 두 배로 섞여 있다.

논문이 주목한 점:

- 자연 영상처럼 렌더링 이미지도 에지가 지배해 파워 스펙트럼이 주파수 제곱에 반비례하는 경향이 있다. 그래디언트(이웃 차이)는 **원래 이미지보다 에너지가 훨씬 작다.**
- 에너지가 작은 신호는 몬테카를로로 추정할 때 분산도 작다. 단, **같은 난수로 만든, 서로 비슷한 경로 쌍**의 차이를 직접 적분해야 한다. 독립 표본 두 묶음의 차이는 이 이점이 없다.
- 이전 그래디언트 영역 렌더링(Lehtinen 2013, Manzi 2014)은 메트로폴리스 광선 수송 위에 있어 구현이 어렵고 수렴이 고르지 않았다. 이 논문은 **보통 경로 추적**에서도 표본 분포를 바꾸지 않고 이득을 얻을 수 있음을 보인다.

## 해법

### 1. 경로 차이 함수와 이동 사상 (3장)

- 픽셀 i 의 각 **기준 경로** x̄ 를 결정적 **이동 사상** `T_ij` 로 옆 픽셀 j 를 지나는 **오프셋 경로**로 옮긴다.
- 그래디언트 표본은 `f(x̄) − f(T_ij(x̄))·|T′_ij|` 다. `|T′|` 은 변수 치환의 야코비안 행렬식으로, 옮기면서 바뀐 경로 밀도를 보정한다.
- 이동은 정확히 한 픽셀만 하므로 픽셀 필터 값이 같아 필터링을 한 번의 합성곱으로 쓸 수 있다.
- 구현에서는 기준 경로마다 상하좌우 4개 이웃으로 옮겨 오프셋 경로 4개를 만든다.

### 2. 대칭 그래디언트와 MIS (5.1절)

이동 사상이 경로 공간 전체의 전단사가 아닐 수 있다(일부 경로를 못 만들거나, 경로 추적기가 절대 만들지 않는 가려진 경로로 보낼 수 있다). 그래서

- 같은 픽셀 차이를 **정방향(i→j)과 역방향(j→i) 두 적분**으로 함께 추정하고, 양쪽 모두에서 생길 수 있는 "대칭" 쌍에 가중치를 주어 합이 1이 되게 한다. 오프셋 경로를 경로 추적기가 만들 수 없으면 가중치 1.
- 대칭 쌍에는 **균형 휴리스틱**을 쓴다: `w_ij(x̄) = p(x̄) / (p(x̄) + p(T_ij(x̄))·|T′_ij(x̄)|)`. 야코비안이 큰 표본(오목한 모서리 근처)은 가중치가 약 `1/|T′|` 이 되어 큰 기여를 상쇄한다. MIS 없이는 이런 이상값이 복원 결과에 얼룩을 남겼다(그림 9).

### 3. 이동 사상 설계 (5.2절)

목표는 경로 차이의 에너지 `‖G‖²` 를 줄이는 것, 즉 오프셋 경로의 기여(× 야코비안)를 기준 경로와 최대한 같게 하는 것이다.

1. 카메라 첫 광선 방향을 한 픽셀 옮긴다(야코비안 1).
2. 현재나 다음 기준 꼭짓점이 (거의) 정반사이면, 기준 경로의 **투영 반벡터를 복사**하며 오프셋 경로를 계속 추적한다. 반사·굴절 각각의 야코비안 식이 있다.
3. 연속된 두 확산 꼭짓점을 만나면 **기준 경로의 다음 꼭짓점에 재연결**한다. 야코비안은 두 기하 항(코사인/거리²)의 비다. 이후 경로는 기준 경로와 같다.

확산/정반사 분류가 어긋나거나 굴절이 전반사로 바뀌는 등 역변환이 안 되는 경우, 재연결 선분이 가려진 경우는 대칭이 아닌 쌍으로 처리한다. 면광원의 BSDF·면적 샘플링까지 합치면 픽셀 차이당 전략이 넷이 되고, 넷 모두 MIS 에 넣는다.

GRIS 는 이동 사상이 그래디언트 영역 렌더링에서 시작되었다고 정리하며, 반벡터 복사·랜덤 리플레이 같은 사상을 [ReSTIR PT](/develop-wiki/knowledge/graphics-xr/restir-pt-shift-mapping-jacobian/)가 이어받았다.

### 4. 스크린드 푸아송 복원 (4.2절)

픽셀 이미지 I 와 그래디언트 ∆ 를 함께 맞추는 최소화 문제로 최종 이미지를 얻는다. 가중 α 가 픽셀 쪽 비중이다.

- 1D 단순화 분석(균일 무작위 표본, 무한 영역 가정)에서 주파수 ω 의 복원 오차는 식 7: `(α⁴‖F‖² + |D(ω)|²‖G‖²) / (n·(α² + |D(ω)|²)²)`, `|D(ω)|² = 2 − 2cos(2πω)`.
- α = ∞ 면 픽셀만, α = 0 이면 그래디언트만 쓴다. 그래디언트만 쓰면 DC 에서 오차가 발산한다.
- 이론상 최적은 `α*² = ‖G‖²/‖F‖²` 이고, 그때 고주파 오차는 픽셀 대비 `4‖F‖²/‖G‖²` 배 이상 줄어든다.
- L2 해는 비편향이라고 한다. 실제로는 이상값을 누르려고 **L1 복원**을 선호하고, α = 0.2 가 모든 장면에서 최적값과 구분되지 않았다고 한다.

```ts
// 식 7: 주파수 w(0~0.5)에서 복원 오차(1/n 생략). F2=‖F‖², G2=‖G‖², a2=α²
function reconError(w: number, F2: number, G2: number, a2: number): number {
  const D2 = 2 - 2 * Math.cos(2 * Math.PI * w);   // 유한 차분 연산자의 파워
  return (a2 * a2 * F2 + D2 * G2) / (a2 + D2) ** 2;
}
const opt = (w: number, F2: number, G2: number) => reconError(w, F2, G2, G2 / F2);
```

### 직접 계산: ‖G‖²/‖F‖² = 0.25 일 때

식 7 에 최적 α² = 0.25 를 넣었다(픽셀 오차를 1로 둔 상대값).

| 주파수 ω | D² (차분 연산자 파워) | 그래디언트만 | 최적 결합 | 픽셀 대비 감소 |
| --- | --- | --- | --- | --- |
| 0.05 | 0.098 | 2.554 | 0.719 | 1.4배 |
| 0.10 | 0.382 | 0.655 | 0.396 | 2.5배 |
| 0.25 | 2.000 | 0.125 | 0.111 | 9.0배 |
| 0.50 (나이퀴스트) | 4.000 | 0.063 | 0.059 | 17배 |

저주파는 거의 픽셀 값에 기대고, 고주파로 갈수록 그래디언트 덕을 크게 본다. 이 표는 기준 표본 n 개에 그래디언트 표본을 **추가로** 얻은 경우의 비교다.

### 논문 결과 (6장)

- Mitsuba 경로 추적기 위에 구현. 기준 n + 오프셋 4n 표본의 비용이 일반 경로 추적 n 표본의 약 **2.5배**였다(오프셋은 몇 선분 뒤 기준 경로에 재연결되므로 싸다).
- 다섯 장면에서 같은 시간 대비 relMSE 가 **5~12배** 줄었다. 확산 위주(Sponza)가 가장 유리하고, 광택면이 많은 장면(Kitchen)은 그래디언트가 시끄러워 덜 유리하다.
- 실측 오차 감소는 이론 예측의 약 두 배였는데, 논문은 그래디언트 4개가 같은 기준 경로를 공유해 서로 상관되어 있기 때문이라고 설명한다. 같은 이유로 이론의 최적 α 는 실제보다 크게 나온다.

## 언제 쓰나

- 오프라인·점진 렌더러에서 **같은 시간에 고주파 잡음을 더 줄이고** 싶고, 결과가 (L2 로) 비편향이어야 할 때. 논문은 적응 필터링 계열이 편향을 도입하는 것과 대비한다.
- 확산 표면 위주 장면. 이동 사상이 두 번째 기준 꼭짓점에 바로 재연결되어 BSDF 값이 거의 변하지 않는다.
- ReSTIR 의 이동 사상·야코비안·MIS 를 이해하려 할 때의 출발점.

## 주의/비용

- **기반 샘플러의 한계를 물려받는다.** 단방향 경로 추적이 못 찾는 경로(어려운 코스틱 등)는 G-PT 도 못 찾고, 이상값·아티팩트가 남는다(논문 결론).
- **광택·정반사.** 경로 차이가 커져 그래디언트가 시끄럽다. 반벡터 복사로 정반사 다양체를 따라가지만 효과는 확산보다 작다. 그림 1 의 드문 예외도 "매우 정반사가 강한 물체" 다.
- **고주파 패턴에서는 손해일 수 있다.** 분석에서 그래디언트 오차는 최악일 때 픽셀의 4배이고, 같은 경로 표본 수(그래디언트를 경로 2개로 셈)로 비교하면 `‖F‖²/‖G‖² < 1` 일 때 이득이 없다.
- **복원 단계 비용.** 프레임마다 스크린드 푸아송 풀이(논문은 L1 선호)가 추가된다. 실시간 예산에 대한 수치는 논문에 없다.
- **L1 의 편향 여부.** 논문은 L2 해가 비편향이라고만 하고, 실험에서 쓴 L1 해의 편향은 다루지 않는다(이 노트에서 미확인).
- **구현 세부가 많다.** 대칭 판정, 4가지 광원 전략의 MIS, 가림 처리 규칙을 빠뜨리면 그래디언트가 틀린다.
