## 개요
hesreallyhim 이 관리하는 Claude Code 생태계 목록이다. 개별 항목에 한두 문장 평가를 붙여 소개하고, 마지막에 "Claude Code 프로젝트 티커"로 GitHub 의 관련 프로젝트 표본을 보여 준다. 현재 목록은 이전 판과 겹치지 않게 새로 고른 것이며, 이전 항목은 `README_ALTERNATIVES/` 에 갱신 없이 보존돼 있다.
**2026-11 기준**: 별 58,269, 마지막 푸시 2026-11-18(매일 갱신). 라이선스는 **CC BY-NC-ND 4.0**(저자 표시·비영리·변경 금지)이라 목록을 가공해 재배포하는 파생물은 만들 수 없고, 링크해서 읽는 용도로 쓴다. 저자는 이 조건이 목록의 일을 해로운 용도로 가져다 쓰는 것을 막으려는 취지라고 밝힌다.
추천 방식도 특이하다. 등록은 GitHub 이슈 폼으로만 받고(PR 불가), 첫 커밋 후 14일이 지났고 이후 커밋이 있거나 별이 100개 이상인 자료만 접수한다.

## 이렇게 활용하라
1. **Start Here 와 From Anthropic 부터 읽는다.** 공식 글과 검증된 입문 자료가 모여 있다.
2. 필요한 분야 섹션에서 항목을 고르고, 해당 **저장소의 최근 커밋과 이슈 상태**를 직접 확인한다. 목록의 평가는 큐레이터 개인 의견이다.
3. 스킬·훅·플러그인은 설치 전에 `SKILL.md`·스크립트·훅 명령을 읽는다.

## 주의
- 목록에 있다는 것은 보안 감사를 받았다는 뜻이 아니다. 훅은 셸 명령을 실행하고 스킬은 스크립트를 동봉하므로 출처를 확인하고 권한을 최소로 준다.
- 문서가 매우 커서(README 약 240KB) GitHub 웹에서 잘려 보일 수 있다. 섹션 목차로 이동하거나 저장소를 클론해 검색한다.
- 영어 자료 중심이며 한국어판은 없다. 같은 분야를 더 넓게 훑으려면 [Awesome MCP Servers](/develop-wiki/oss/awesome-lists/awesome-mcp-servers/)나 [Awesome Claude Code Subagents](/develop-wiki/oss/agent-skills/awesome-claude-code-subagents/)를 함께 본다.
