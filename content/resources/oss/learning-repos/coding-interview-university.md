## 개요
John Washam 이 대형 IT 기업 면접을 준비하며 만든 **여러 달짜리 공부 계획**이다. 주제마다 강의 영상·글·연습 문제 링크와 체크박스가 있어, 저장소를 포크해 체크하며 진도를 관리하도록 설계됐다. 프런트엔드·풀스택이 아니라 소프트웨어 엔지니어링(CS 기초) 대상이라고 README 에 명시한다. 2026-11 기준 별 약 36.4만, 라이선스 CC-BY-SA-4.0. 최근 6개월 커밋 25건, 마지막 2026-11-07.

번역이 30개 가까이 있고 **한국어 번역(translations/README-ko.md)이 2026-11 에도 갱신**됐다.

## 이렇게 활용하라
1. **저장소를 포크하고 체크박스를 쓴다.** README 의 "If you're comfortable with git" 절차대로 포크한 뒤 공부한 항목을 `[x]` 로 바꿔 커밋한다.
2. **언어 하나를 정해 끝까지 쓴다.** 자료 구조를 직접 구현할 언어(C·Python·Java 등)를 고른다.
3. **"Daily Plan" 루틴을 따른다.** 하루 한 주제를 보고, 구현하고, 문제를 푼다.
4. **개념은 이 사이트의 알고리즘 노트로 복습한다.** [Big-O](/develop-wiki/knowledge/algorithms/big-o-complexity/) · [해시 테이블](/develop-wiki/knowledge/algorithms/hash-table/) · [BFS·DFS](/develop-wiki/knowledge/algorithms/bfs-dfs/) · [동적 계획법](/develop-wiki/knowledge/algorithms/dynamic-programming/)
5. **문제 풀이는 따로 붙인다.** 면접 직전 단계는 [Tech Interview Handbook](/develop-wiki/oss/learning-repos/tech-interview-handbook/) 의 문제 목록이 더 압축적이다. 시스템 설계는 [System Design Primer](/develop-wiki/backend/learning/system-design-primer/) 로 이어 간다.

## 주의
- 분량이 많다. 저자 기준 수개월 이상 걸리며, 면접이 가까우면 핵심(자료 구조·정렬·그래프·DP)만 골라야 한다.
- 링크된 강의 영상 일부는 오래됐거나 비공개로 바뀌었을 수 있다.
- README 중간에 후원·광고 영역이 있다.
