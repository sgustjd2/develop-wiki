## 문제

- 인터뷰에서 사람들은 자기 습관을 정확히 회상·설명하지 못한다. 실험실 테스트는 실제 환경(방해, 도구 조합, 시간 압박)을 빼 버린다.
- 한 번의 세션으로는 "며칠~몇 주에 걸친 행동"을 볼 수 없다.
- 방법 선택의 큰 그림은 [사용자 리서치 방법 고르기](/develop-wiki/knowledge/ui-ux/ux-research-method-selection/)에 있다.

## 해법

### 현장 조사 (NN/g 요약)

복잡한 시스템·전문가 사용자·깊이 있는 프로세스를 이해하는 발견 단계 방법. 연구자가 소수 사용자의 실제 작업을 현장에서 관찰하며 질문한다.

네 원칙: **맥락**(일이 일어나는 곳에서), **파트너십**(대화 주도권 공유), **해석**(연구자의 해석을 참가자가 바로잡음), **초점**(연구 목표로 관찰·질문 범위 제한).

세션 구조:

1. 프라이머: 라포, 목적, 비밀 유지·녹화 동의, 일의 개요.
2. 전환: 말하기에서 실제로 일하기로 명시적으로 전환, 중간에 질문한다고 예고.
3. 맥락 인터뷰: 관찰하다가 이해 안 되는 행동이나 자신의 해석을 묻는다. 남발하면 이후 행동을 오염시킨다.
4. 마무리: 요약해 참가자가 확인·정정.

### 다이어리 스터디 (NN/g 요약)

원격·비동기로 장기 행동, 습관, 사용 빈도·시점, 동기, 인식 변화, 전체 고객 여정을 본다.

- **기간**: 행동 빈도와 활동 소요에 맞춘다. 예시: 하루 여러 번 쓰는 어시스턴트 약 1주, 주 1~2회 배달 앱 약 3주, 통신 요금제 구매 약 2주.
- **인원**: 균질한 소규모 발견 약 5~12명, 다양한 대규모 약 12~30명, 매우 넓은 학술 규모 약 30~50명. 이탈을 감안해 더 모집.
- **운영**: 항목 도착 즉시 검토해 기억이 신선할 때 후속 질문, 연락 수단을 사전에 정하고 정기 리마인더, 사전 안내와 사후 인터뷰.
- **인센티브** 가이드: 미국 일반 표본 기준 총 참여 시간 1시간당 약 40달러(대상에 따라 조정), 1주 초과 시 단계 지급. 한국 현황은 원문에 없다.

## 비교

| | 현장 조사 | 다이어리 스터디 |
| --- | --- | --- |
| 데이터 | 관찰 + 현장 질문 | 참가자 자기 기록 |
| 시간 범위 | 한 번의 세션 | 며칠~몇 주 |
| 비용 | 이동·일정 필요 | 원격이라 상대적으로 저렴 |
| 약점 | 연구자 영향 | 기록 누락·기억 의존 |

## 언제 쓰나

- 새 영역 발견, 전문가 업무 도구 설계 전 현장 조사.
- 습관·여정이 긴 제품(구독, 헬스, 구매 결정)에 다이어리 스터디. 결과는 [여정 지도](/develop-wiki/knowledge/ui-ux/journey-map-service-blueprint/)·페르소나로 이어진다.

## 체크리스트

- [ ] 연구 목표를 문장으로 적고 관찰 항목을 좁혔다
- [ ] 현장 조사: 전환 멘트와 "평소처럼 일하세요" 요청을 준비했다
- [ ] 다이어리: 파일럿, 기간, 기록 도구, 리마인더 템플릿, 응답 상한을 정했다
- [ ] 결과는 팀이 함께 어피니티 매핑한다(NN/g가 현장 조사에 권장)

## 흔한 실수·주의

- **현장 조사가 인터뷰로 변한다.** 설명만 듣고 있으면 일하게 되돌린다.
- **불만 토로 세션이 된다.** 실제 작업 방식으로 돌아간다.
- **다이어리에서 최소 응답 수를 무리하게 요구하거나 상한을 두지 않는다.** 행동이 왜곡되거나 보상 때문에 항목을 지어낸다.
- **기록 시점이 한정된다.** 오후 한 번이면 아침 활동이 빠진다.
- **구체적인 예시 항목을 줘 참가자를 유도한다.**
