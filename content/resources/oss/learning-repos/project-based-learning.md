## 개요
"애플리케이션을 처음부터 만들며 배우는" 튜토리얼을 C/C++, C#, Go, Java, JavaScript, Python, Rust 등 **주 언어별로** 나눠 모은 목록이다. 웹 앱, 챗봇, 웹 스크래퍼, 인터프리터, 네트워크 프로그램처럼 결과물이 분명한 튜토리얼이 많다. 2026-11 기준 별 약 29만, 라이선스 MIT. 최근 6개월 커밋 43건(마지막 2026-11-16)이며, 죽은 링크를 정기적으로 정리하는 워크플로가 있다.

## 무엇이 들어 있나
| 섹션 | 내용 |
| --- | --- |
| C/C++ | 셸, 인터프리터, 텍스트 에디터, 네트워크 프로그래밍, OpenGL |
| JavaScript · HTML and CSS | 웹 앱(React, Next.js, Angular, Vue, Node), D3.js, 모바일 앱 |
| Python | 웹 스크래핑, 웹 앱, 봇, 데이터 사이언스, 머신러닝, OpenCV, 딥러닝 |
| Go · Rust · Java · Kotlin · Swift | 언어별 서버·CLI·앱 튜토리얼 |
| C# · Clojure · Dart(Flutter) · Elixir · Erlang · F# · Haskell · Lua · OCaml · PHP · R · Ruby(Rails) · Scala | 그 밖의 언어 |
| Additional Resources | 비슷한 목록과 학습 사이트 |

## 이렇게 활용하라
1. **이미 문법을 아는 언어 섹션으로 간다.** 새 언어 문법 공부와 프로젝트를 동시에 하면 진도가 느리다.
2. **결과물이 실제로 쓸모 있는 것을 고른다.** 예: Python → Web Scraping 으로 관심 사이트 데이터를 모으고, [Public APIs](/develop-wiki/oss/awesome-lists/public-apis/) 의 API 를 붙여 본다.
3. **튜토리얼을 끝내면 기능 하나를 스스로 추가한다.** 인증, 테스트, 배포(Docker) 중 하나를 더하면 포트폴리오가 된다.
4. **낮은 수준까지 내려가 보고 싶으면** [Build Your Own X](/develop-wiki/oss/learning-repos/build-your-own-x/) 로 넘어간다.

## 주의
- 외부 블로그·영상 링크라 튜토리얼의 프레임워크 버전이 오래된 경우가 많다(예: 구버전 React 클래스 컴포넌트, 구버전 Rails). 공식 문서와 대조하며 따라간다.
- 한국어 번역은 없다.
