# 주간 조사 초안 검토 (2026-11-24)

대상: 2026-11-22 Hermes 주간 조사(첫 실행)가 만든 초안 4개 + 출처 부족 2개.

| 초안 | 판정 | 결과 |
| --- | --- | --- |
| STRIDE 인증 가능 견고 추정 솔버 | 버림 → 직접 작성 | 로컬 모델이 주제와 무관한 DiffReach(도달 가능성 분석) 저장소를 읽었다. Yang & Carlone T-PAMI 2022 논문(arXiv 2109.03349)에서 새로 작성: robotics/stride-certifiable-outlier-robust-perception-solver |
| Friedman 검정 | 재작성 | 출처가 블로그 2개와 Wikipedia 였다. scipy·Demšar 2006 등 1차 출처와 직접 계산으로 새로 작성: ui-ux/friedman-test-repeated-ordinal |
| RFC 9701 JWT 인트로스펙션 | 보강 재작성 | 인용은 정확했으나 문단 4개로 얇았다. RFC 전문을 읽고 새로 작성: security/rfc-9701-jwt-introspection-response |
| Envoy zone-aware·패닉 임계 | 재작성 | 제목과 달리 패닉만 다뤘고 v1.12.4 문서를 읽었다. 최신 문서·소스로 새로 작성: performance/envoy-zone-aware-routing-panic-threshold |
| Epain 2014 일정 각 퍼짐 디코딩 | 출처 부족 → 직접 작성 | 로컬 모델이 무관한 사이트만 찾았다. 원문은 EAA DAEL 의 다른 문서 번호(51959; 2012 EPAD 논문은 65156)에 있었고, 전문 10쪽을 받아 작성: graphics-xr/ambisonic-decoding-constant-angular-spread |
| LeaseGuard(SIGMOD 2026) | 출처 부족 → 직접 작성 | 같은 이름의 보험 회사 페이지가 섞여 초안이 나오지 않았다. arXiv 2512.15659(SIGMOD 2026, Davis·Demirbas·Deng)를 직접 읽고 작성: distributed-systems/leaseguard-raft-lease-read-optimization |

## 로컬 모델 초안에서 확인된 한계
- 스크립트 검증(인용문이 내려받은 원문에 있고 숫자가 근거 안에 있음)은 통과했지만 **출처가 주제에 맞는지**는 걸러지지 않았다(STRIDE → 다른 프로젝트, Friedman → 블로그, Envoy → 구버전 문서·주제 일부).
- 무관한 출처가 섞이는 경우(LeaseGuard → 같은 이름의 보험 회사)는 관련성 판정을 강화했지만 완전하지 않다.
- 4개 모두 문장 단위로는 원문과 일치했으므로 "정확한 인용 + 잘못된 주제" 조합에 주의해서 검토해야 한다.

## 독립 팩트체크 (새 노트 4개)
반드시 수정 0건, 수정 권장 16건(모두 반영).
- STRIDE: 논문 본문과 표 2 의 배수가 다름(본문 10배 vs 표 2 약 2~5배)을 병기, 랭크 1 걸음 채택 서술을 논문 식(29) 기준으로 정정, `f*` 정의 명시, 표 2 시간 범위(11~4,274 s)를 확인.
- Friedman: 정확 순열 p 0.00016 으로 근사 p(0.00058)가 약 3.6배 보수적임을 반영("같은 자릿수" 삭제), scipy 의 NaN 처리(`nan_policy`) 정정, 전부 동점 경계 사례 추가. 순위합·Q·W 는 scipy 없이 독립 재계산으로 일치.
- RFC 9701: 호출자 인증 400 규칙의 절 번호(5절 Note), 8.1 인용 범위, 비교표의 RFC 9068 열이 일반 성질임을 명시, errata 없음(조회일 기준) 반영.
- Envoy: 이상치 감지 제외 호스트와 패닉 식의 `excluded` 구분, zone-aware 를 건너뛰는 경우 4가지와 통계 이름 정정, locality 가중치 32% 의 정수 절사 설명, `force_local_zone`·`locality_basis` 의 proto 위치 확인.

## 미확정
- STRIDE 논문 부록(증명)과 표 2 열 배치(추출 순서 추정), MIT-SPARK 저장소 라이선스.
- Friedman 1937 원문, Conover·Hollander–Wolfe 본문, Kendall's W 효과 크기 경계.
- RFC 7662·8414·8725·9700·7591·7519 원문(RFC 9701 이 인용한 범위만).
- Envoy 는 직접 실행해 재현하지 않았고 문서가 dev 빌드(1.41.0-dev)다.

## LeaseGuard 노트 (추가 작성)
독립 팩트체크 반드시 수정 2건·수정 권장 5건 모두 반영: 논문 쪽수(15쪽), CockroachDB 2020 논문 리스 분류(사용자 범위는 노드 생존에 묶고 시스템 범위는 만료 리스)로 정정, 필자 정리 표시 2곳 보강, TiDB Placement Driver 귀속, 선형화 검사 서술(수백 연산 이력은 검사 시간 서술이지 범위 상한이 아님). 규칙표·부등호·시계 가정·TLA+ 설정(저장소 `mcLeaseGuard.cfg` 기준, 논문이 밝힌 범위가 아님)·실험 조건은 원문과 일치.
미확정: 초록의 쓰기 ~1,000→~10,000/s 의 본문 부하 조건, 그림 수치, 논문 증명, MongoDB 배포 여부, LogCabin 라이선스(NOASSERTION).

## Epain 2014 노트 (추가 작성)
독립 팩트체크 반드시 수정 0건·수정 권장 4건 모두 반영: JND 서술의 "3차 이상"을 원문대로 4차 이상으로, "스피커 수 조건 없음"을 원문 장점(임의 차수·불규칙 배치)과 필자 추정으로 분리, 책 폭 척도 절 번호(2.3.1), 2D 환산 표기와 64.1/64.0° 반올림. 원 논문의 퍼짐 정의 `2·arccos(2‖rE‖−1)`(식 11)이 EPAD 노트·책의 `2·arccos‖rE‖` 와 다르다는 점을 환산표로 정리. 책 3.2절의 "가상 음원의 방향·가중 최적화" 요약은 논문의 창 구경 α 최적화와 정확히 대응하지 않음을 확인하고 MDAP 노트의 "Epain 논문 미열람" 문구를 갱신.
미확정: 논문 그림 1~5 의 값과 CARLab 스피커 좌표, 이후 지각 평가·청취 실험, 구현 툴박스, 3D 에서의 지각적 타당성, JND 본문(약 6°)·그림 캡션(약 10°) 불일치 이유.

## AllRAD 2012 원문 / DAGA 2013 노트
- AllRAD 2012(Zotter·Frank, JAES 60(10):807–820): 서지는 OpenAlex·Semantic Scholar·저자 출판 목록으로 확인(DOI 없음). 공개 사본이 없다(OpenAlex·Semantic Scholar 모두 비공개, AES 페이지 403, 저자 목록에 PDF 링크 없음). 접속 확인·유료 장벽 우회는 하지 않았고 비정식 사본(scispace)은 열지 않아 노트는 만들지 않았다. 소속 기관 AES 구독으로 PDF 를 받아 경로를 알려 주면 작성 가능.
- 대신 저자 공개 PDF 인 Zotter·Frank·Pomberger "Comparison of energy-preserving and all-round Ambisonic decoders"(4쪽; 학회명·연도는 PDF 에 없어 미확인)를 직접 읽고 `allrad-plus-mvlad-decoder-comparison` 노트를 작성했다. AllRAD+ 계수 `g_AllRAD=1/√2, g_SAD=1/√8`(식 14, 논문이 어림이라 부름), MVLAD `G·Yᵀ(YYᵀ)⁻¹` 가 균일 샘플링에서 AllRAD 와 같아짐(직접 계산: 균일 S=26·50 에서 ~1e−15, 불균일 S=70 에서 어긋남), 폭 정의 `2·arccos‖rE‖`(Epain 2014 정의와 다름).
- 독립 팩트체크 반드시 수정 1건(EPAD 식 (8) 표기 `V̌` 오기)·수정 권장 4건 반영. 직접 계산 중 "AllRAD 에너지 두 배/절반" 추정은 재현되지 않았고(1.14~1.18배, 0.82~0.87배) 노트에 그대로 밝혔다(AllRAD 의 G 정규화 차이일 수 있음).
- 미확정: AllRAD 2012 본문, 그림 1~6 수치, 학회명·연도·개최지, 참고문헌 5편 원문, 논문 이후 청취 평가.

## Pernaux 1998 VBIP 원문 노트
DAFx 아카이브(https://www.dafx.de/paper-archive/1998/PER15.PS.pdf)의 공개 PDF 5쪽을 읽고 `vbip-vector-base-intensity-panning-origin` 노트를 작성했다. 서지는 Epain 2014 참고문헌 [17]·PDF 표지로 확인(쪽 76–80 은 Epain 표기만). VBIP 는 이 논문이 도입했다고 쓰는 이름이며 700 Hz 위 고주파 법칙(아래는 VBAP, 합쳐 VBP), 식은 2D 쌍만, 3D 식 없음. "제곱합 정규화"는 VBAP 도 하며 차이는 역행렬 해를 진폭으로 읽느냐 제곱 이득으로 읽느냐(직접 계산: 5개 링에서 VBAP 는 rV 방향 오차 0·rE 오차 최대 14.0°, VBIP 는 정반대).
독립 팩트체크 반드시 수정 1건(청취 실험 음원 위치 `0°-22,5°-90°-180°` 의 하이픈을 음수 부호로 오독 → 0°, 22.5°, 90°, 180°)·수정 권장 4건 반영(Genesis 출력 "최대 16개", "처음" 단정 완화, "might recommend Ambisonics", 원문 식 오타 위치·ITU 배치 출처 표시). 원문 식의 흠 두 곳(VBAP 행렬 `sinθ₁` 오타, VBIP 중간식 불일치)은 이미지로 확인되어 판정이 맞음. MDAP 노트의 "VBIP 최초 제안 문헌 미열람" 문구를 이 노트 링크로 갱신.
미확정: 쪽 번호, 이 논문이 VBIP 의 최초 제안인지 다른 문헌 교차 확인, Pulkki 1997·Gerzon 1992 본문, 그림 2·3 의 정확한 값.

## AllRAD 노트 보강 (공개 자료)
AllRAD 2012 원문은 구하지 못해 `ambisonics-speaker-decoders-maxre-allrad` 에 이미 팩트체크를 거친 후속 노트(AllRAD+·MVLAD 비교, Epain 2014 일정 각 퍼짐)의 내용을 "후속 공개 자료로 확인한 것" 절로 옮겨 보강했다(AllRAD 두 단계 서술이 후속 논문과 일치, 반원 9개 스피커 예에서의 논문 서술, AllRAD+·MVLAD, 퍼짐 정의 차이). 모든 서술을 "원문이 아니라 후속 논문 요약"으로 귀속했고 출처 메모에 2026-11-24 의 접근 시도 결과(OpenAlex·Semantic Scholar 비공개, AES 403, 저자 목록에 PDF 링크 없음)를 추가. 새 사실은 만들지 않았으므로 별도 팩트체크는 하지 않았다(내용은 이미 독립 검증된 두 노트에서 옮김). 2012 원문은 여전히 미확인.
