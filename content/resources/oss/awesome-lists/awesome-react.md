## 개요
React 가 베타이던 시절부터 이어진 목록으로, 지금은 **React** 와 **React Native** 두 부분으로 나뉘어 각 분야 대표 라이브러리를 짧게 소개한다. 목록이 비교적 짧고(README 약 270줄) 오래된 항목을 정리해 온 편이다. 2026-11 기준 별 약 7.5만, 라이선스 CC BY 4.0(README 표기).

## 이렇게 활용하라
1. **필요한 분야 하나만 연다.** 예: 서버 상태 관리가 필요하면 State Management and Data Fetching 에서 후보를 고른다.
2. **이 사이트의 비교 항목으로 넘어간다.** [TanStack Query](/develop-wiki/frontend/state-data/tanstack-query/) · [Zustand](/develop-wiki/frontend/state-data/zustand/) · [Redux Toolkit](/develop-wiki/frontend/state-data/redux-toolkit/) · [React Hook Form](/develop-wiki/frontend/state-data/react-hook-form/) 처럼 사용법이 정리된 항목이 있다.
3. **React 버전 호환성을 확인한다.** React 19 와 서버 컴포넌트 지원 여부, peerDependencies 범위를 본다.
4. **React Real Apps 의 코드를 읽는다.** 폴더 구조·상태 관리 방식을 실제 프로젝트에서 참고한다.
