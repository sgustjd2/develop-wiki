## 문제

원격 조작은 투명성(멀리 있는 환경을 그대로 느끼게)과 안정성이 맞선다. 딱딱한 벽과 빈 공간을 모두 다뤄야 하니 고정 이득·고정 감쇠 설계는 최악 조건에 맞춰 보수적이 된다.

- 사람과 환경을 수동으로 가정하면, 그 사이의 **원격 조작기 2-포트**만 수동이면 전체가 안정하다(충분조건). 원고는 사람을 수동으로 보는 근거로 Hogan 의 실험을 든다.
- 비선형 동역학, 모델 불확실성, 다자유도 때문에 모델 기반(적응 제어 등) 설계는 어렵다.
- 주파수 영역 수동성 설계(파동 변수, 고정 가상 커플링)는 고정 감쇠라 성능을 늘 깎는다.

## 해법 1: 2-포트 PO/PC (지연 없음)

### 관측기

두 포트의 전력을 더해 누적한다(원고 식 3): `E_obsv(n) = ΔT Σ (f₁v₁ + f₂v₂)`. 음수가 되면 그만큼 에너지를 만들어 낸 것이다.

### 제어기 배치 원칙

- **포트마다 PC 를 하나씩** 둔다. 한쪽에만 두면 그 포트 속도가 0 일 때 다른 포트에서 나오는 에너지를 소산할 수 없다.
- **능동인 포트에서만** 켠다. 수동 포트의 흡수를 늘려 합계를 맞추는 것도 수학적으로는 되지만, 그 포트가 무한 에너지원(힘·속도원)에 붙어 있으면 전체 에너지가 유계가 아닐 수 있어 물리적으로 맞지 않다고 원고는 설명한다.
- 포트 상태는 실시간으로 `f·v ≥ 0` 이면 수동, `< 0` 이면 능동으로 판정한다.

### 절차 (임피던스 인과, 직렬 PC 두 개)

`W(n) = Σ_{k<n}(f₁v₁ + f₄v₄) + f₂(n)v₂(n) + f₃(n)v₃(n)` 를 계산하고(왼쪽 포트 `v₁ = v₂`, 오른쪽 `v₄ = v₃`), 경우를 나눈다.

| 경우 | 조건 | 왼쪽 `α₁` | 오른쪽 `α₂` |
| --- | --- | --- | --- |
| 1 | `W ≥ 0` | 0 | 0 |
| 2 | `W < 0`, 왼쪽만 능동 | `−W / v₂²` | 0 |
| 3 | `W < 0`, 오른쪽만 능동 | 0 | `−W / v₃²` |
| 4.1 | 둘 다 능동, `W(n−1) + f₃v₃ < 0` | `−f₂v₂ / v₂²` | `−(W(n−1) + f₃v₃) / v₃²` |
| 4.2 | 둘 다 능동, `W(n−1) + f₃v₃ ≥ 0` | `−W / v₂²` | 0 |

출력은 `f₁ = f₂ + α₁v₂`, `f₄ = f₃ + α₂v₃`. 4 번은 감쇠를 두 포트에 나누는 한 예일 뿐이고(왼쪽 우선), 원고도 다른 분배가 가능하며 최적 분배는 연구 중이라고 쓴다. 감쇠는 능동 포트의 힘을 많아야 0 까지 줄인다(부호를 뒤집지 않는다).

```ts
// 2-포트 직렬 PC (원고 Step 1~6 의 경우 분기). v2·v3: 입력 속도, f2·f3: 제어기 출력 힘
export function makeTwoPortPC() {
  let past = 0; // Σ_{k<n}(f1 v1 + f4 v4)
  return (v2: number, v3: number, f2: number, f3: number) => {
    const p2 = f2 * v2, p3 = f3 * v3, W = past + p2 + p3;
    let a1 = 0, a2 = 0;
    if (W < 0) {
      if (p2 < 0 && p3 >= 0) a1 = -W / (v2 * v2);
      else if (p2 >= 0 && p3 < 0) a2 = -W / (v3 * v3);
      else if (p2 < 0 && p3 < 0) {
        if (past + p3 < 0) { a1 = -p2 / (v2 * v2); a2 = -(past + p3) / (v3 * v3); }
        else a1 = -W / (v2 * v2);
      }
    }
    const f1 = f2 + a1 * v2, f4 = f3 + a2 * v3;
    past += f1 * v2 + f4 * v3;
    return { f1, f4 };
  };
}
```

### 어디에 다나 — 제어기 2-포트

사람·환경 쪽 힘과 속도(`f_h, v_h, f_e, v_e`)는 잴 수는 있어도 실시간으로 바꿀 수 없다. 그래서 수동인 블록을 빼 나간다. 마스터·슬레이브의 **기계부**는 자체 소산이 있어 능동이 아니라고 보고, **양방향 제어기(소프트웨어 + 통신)** 2-포트만 수동으로 만든다. 그 포트의 짝 변수는 작동기 구동력과 작동 지점 속도(`f_m, v_m`, `f_s, v_s`)라 실시간으로 읽고 바꿀 수 있다. 모터는 어드미턴스 인과라 제어기는 양쪽 다 임피던스 인과이고, 그래서 **직렬 PC** 를 쓴다.

## 해법 2: 통신 지연이 있을 때 (Ryu·Preusche 2007, Ryu 2008)

지연이 있으면 두 포트의 전력을 **같은 샘플 시각에** 더할 수 없어 위의 관측기가 실시간으로 성립하지 않는다. IFAC 2008 논문이 요약한 수정안:

1. 포트마다 에너지를 **들어온 것**과 **나간 것**으로 나눠 누적한다(식 5·6). `f·v > 0` 이면 입력에, `< 0` 이면 출력에 더한다. 1-포트 수동성은 `E_in(k) ≥ E_out(k)` 로 바뀐다.
2. 한 포트의 출력 에너지의 주된 원천은 건너편 포트의 입력 에너지라고 보고, 다음 **충분조건**을 쓴다(식 13·14): 슬레이브 출력 ≤ 마스터 입력, 마스터 출력 ≤ 슬레이브 입력.
3. 지연 `D_MS`, `D_SM` 이 있으면 건너편 입력은 지연된 값만 안다: `E_in^M(k − D_MS) ≥ E_out^S(k)`, `E_in^S(k − D_SM) ≥ E_out^M(k)` (식 15·16). 지연 동안 늘어난 입력 에너지는 항상 0 이상이므로, 이 조건이 지켜지면 실제 지연과 상관없이 제어기 2-포트가 수동이다(식 17~19). 지연이 **시변이어도** 성립한다고 한다.
4. 구현: 각 포트에 입력 PO 와 출력 PO 를 따로 두고, 입력 에너지 값을 건너편으로 보내 그쪽 PC 의 상한으로 쓴다.

## 논문이 보고한 것

- **지연 없는 실험**(원고, 2 자유도 5절 링크 마스터·슬레이브, 관절당 2 Nm, 1000 Hz 동기, 위치-힘 구조, 슬레이브 PD): 투명성을 일부러 정상 한계 이상으로 올려 자주 불안정하게 만든 뒤 PC 를 붙였다.
  - 강성 약 150 kN/m 이상 강철 벽에 약 120 mm/s 로 접촉: PC 없이 진동 지속, PO 는 접촉마다 더 음수. PC 를 켜면 약 7 번 튕긴 뒤 안정. 첫 튕김은 수동, 이후 작은 튕김이 능동이었다.
  - 약 30 mm/s 로 접촉 후 기울어진 벽을 따라가기: PC 없이 t = 1.5 s 이후 진동이 커졌고, PC 를 켜면 안정된 표면 추종.
  - 스펀지 같은 부드러운 환경은 두 경우 모두 안정했지만 PO 가 100~200 ms 동안 잠깐 음수가 되기도 했다.
- **시변 지연 실험**(IFAC 2008, PHANToM 마스터·슬레이브, UDP, 무선 패킷 반사기): 왕복 지연 평균 약 180 ms(175~275 ms), 패킷 약 3 분의 1 손실, 위치-위치 구조 `K_p = 100 N/m`. PC 없이 자유 공간에서 마스터가 진동하고 약 3.7 s 이후 슬레이브가 발산했다. PC 를 켜면 자유 공간과 딱딱한 접촉 모두 안정했다. 남은 문제로 PC 의 잡음 섞인 동작을 든다.

### 직접 확인: 2-포트 PC 의 에너지 수지

위 `makeTwoPortPC` 와 같은 로직을 Node.js 로 돌렸다(`twoport_pc.mjs`). 각 샘플에 무작위 속도·힘을 주되 힘에 속도 반대 방향 편향을 넣어 평균적으로 에너지를 내놓는 제어기로 만들었다. 20 만 샘플에서 PC 없이 누적 에너지는 −15397(임의 단위, 끝값 −15394)까지 내려갔고, PC 를 거친 포트 에너지 `Σ(f₁v₁ + f₄v₄)` 의 최솟값은 −2.8×10⁻¹⁶(부동소수 오차)로 0 이상이 유지됐다. PC 는 샘플의 20.4% 에서 켜졌다. `W(n−1)` 은 PC 적용 후 직전 샘플까지의 누적 포트 에너지로 해석했다(원고 표기만으로는 자명하지 않음). 이 모형은 물리 시스템이 아니라 원고의 경우 분기가 에너지 조건을 지키는지만 확인한 것이다.

## 후속: 기준 에너지 추종 (Ryu·Preusche·Hannaford·Hirzinger, TCST 2005) — 초록 수준

본문을 구하지 못해 초록(출판사 초록, OpenAlex·DLR elib 경유)에서 확인한 것만 쓴다.

- 상업용 PHANToM 에 PO/PC 를 적용하니 안정은 됐지만 장치의 **고주파 모드를 자극**했다.
- 처방: PO 의 기준을 고정된 0 대신 **시간에 따라 변하는 목표 에너지**로 두고, 실제 입력 에너지가 그 목표를 따라가게 한다. 소산을 시간에 나눠 PC 가 갑작스러운 충격 없이 부드럽게 동작한다.
- 강성 `K = 5000 N/m` 의 PHANToM 에서 안정하고 부드러운 접촉을 보고한다. 같은 생각으로 **재설정(에너지 저금) 문제**와 능동 환경 표시 문제도 풀 수 있다고 쓴다.
- 목표 에너지를 어떻게 만드는지(식, 매개변수), 정량 결과는 **미확인**이다.

## 언제 쓰나

- 이미 쓰던 양방향 제어 구조(위치-힘, 위치-위치 등)를 바꾸지 않고 안정성만 덧대고 싶을 때. 원고 결론은 "제어기 코드 몇 줄 추가"로 표현한다. 성능(투명성)을 높이는 방법이 아니라, 높게 잡은 성능을 유지하면서 안정을 보장하는 방법이다.
- 모델·매개변수 추정 없이 딱딱한 접촉·표면 추종에서 진동을 막아야 할 때.
- 인터넷·무선처럼 지연이 변하고 패킷이 빠지는 통신 위에서 원격 조작할 때(입력·출력 분리 버전).

## 주의/비용

- **저속·작은 힘에서 PC 가 거칠다.** `α = −W/v²` 라 속도가 작을 때 큰 감쇠가 나온다. IFAC 2008 도 PC 의 잡음 섞인 동작을 남은 문제로 든다. 기준 에너지 추종은 이 문제(충격성 동작, 고주파 모드 자극)를 겨냥한 후속이다.
- **충분조건이라 보수적일 수 있다.** 지연 버전의 "출력 ≤ 건너편 입력" 은 원래 조건보다 강하다. 사람·장치의 소산을 추정해 기준을 낮추는 것은 원고의 향후 과제였다.
- **사람·환경 수동 가정.** 환경이 능동(예: 움직이는 물체, 능동 가상 환경)이면 전제가 깨진다.
- **감쇠 분배는 설계 선택.** 두 포트가 동시에 능동일 때의 분배(왼쪽 우선 등)에 따라 조작자가 느끼는 힘이 달라진다. 최적 분배는 원고 시점에서 열린 문제였다.
- 위치 추종 성능은 보장하지 않는다. 지연 버전은 소산으로 에너지를 버리므로 마스터-슬레이브 위치가 벌어질 수 있다(이 노트에서는 확인하지 않았다).
