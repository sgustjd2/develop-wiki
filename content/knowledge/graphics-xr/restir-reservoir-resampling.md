> 출처 메모: Bitterli·Wyman·Pharr·Shirley·Lefohn·Jarosz, "Spatiotemporal reservoir resampling for real-time ray tracing with dynamic direct lighting"(ACM TOG 2020) 의 NVIDIA 공개 PDF 본문 2~6절(준비 지식, 스트리밍 RIS, 시공간 재사용, 편향 제거, 구현 선택)과 결과 일부, 8.1절 한계를 읽었다. 부록의 증명, 비교 방법(Moreau 등 광원 BVH)의 세부, 후속 연구(ReSTIR GI, PT 등)는 읽지 않았다. 아래 수치 실험은 광원 64개짜리 장난감 모형(Python)이며 논문 이미지 품질의 재현이 아니다.

## 문제

장면에 **동적 발광 삼각형이 수천~수백만 개** 있을 때 한 픽셀의 직접 조명은 광원마다 그림자 광선을 쏘면 감당이 안 된다. 광원 몇 개만 무작위로 고르면 노이즈가 크다. 전처리 자료구조(광원 BVH 등)는 광원이 움직이면 갱신 비용이 든다. 필요한 것은 **자료구조 없이 중요한 광원을 고르는** 방법이다.

## 해법

### 1. RIS: 쉬운 분포로 뽑아 목표 분포를 흉내

RIS 는 샘플러 `p` 에서 후보 `M` 개를 뽑고, 목표 함수 `p̂`(예: 그림자 제외 기여 `ρ·Le·G`)로 가중치 `w = p̂/p` 를 매겨 하나를 확률 비례로 고른다. 선택된 샘플 `y` 의 추정은 `f(y)/p̂(y) · (1/M)Σw` 다. `M` 이 클수록 `y` 의 분포가 `p̂` 에 가까워지고, 값비싼 그림자 광선은 **살아남은 표본에만** 쏜다.

### 2. 가중 저수지 표본추출: 후보를 저장하지 않는 스트리밍

후보를 `M` 개 저장하지 않고 하나씩 흘려보낸다. 저수지는 `{y, wsum, M}` 만 가진다. 새 후보 `x` 를 받으면 `wsum += w`, `M += 1`, 확률 `w/wsum` 으로 `y = x` 로 교체한다. 저장량은 상수, 계산은 `M` 에 선형이다.

```ts
interface Reservoir { y: number; wsum: number; M: number; W: number }

function update(r: Reservoir, x: number, w: number, rand: () => number) {
  r.wsum += w;
  r.M += 1;
  if (rand() < w / r.wsum) r.y = x;
}

// 다른 저수지를 합치기: 그 저수지의 선택 y 를 "가중치 p̂_q(y)·W·M" 짜리 후보 하나로 취급
function combine(q: (x: number) => number, rs: Reservoir[], rand: () => number): Reservoir {
  const s: Reservoir = { y: -1, wsum: 0, M: 0, W: 0 };
  for (const r of rs) {
    update(s, r.y, q(r.y) * r.W * r.M, rand);
    s.M += r.M - 1; // update 가 M 을 1 올렸으므로 보정
  }
  s.W = s.wsum / s.M / q(s.y); // 식 (6) 의 보정 인자
  return s;
}
```

핵심 성질은 **저수지끼리 합치는 데 원래 후보 목록이 필요 없다**는 것이다. 합치는 비용은 저수지 수 `k` 에 대해 `O(k)` 이고, 결과는 두 입력 스트림을 이어 붙여 저수지 표본추출한 것과 수학적으로 같다.

### 3. 시공간 재사용 (논문 알고리즘 5)

1. 각 픽셀이 `M` 개 후보로 저수지를 만든다(광원 파워 비례 샘플링, 논문은 `M = 32`).
2. **가시성 재사용**: 고른 표본이 가려져 있으면 그 저수지를 버린다. 가려진 표본이 이웃에 번지지 않는다.
3. **시간 재사용**: 모션 벡터로 이전 프레임 같은 점의 저수지와 합친다. 매 프레임 합치므로 사실상 과거 전 프레임의 후보가 누적된다.
4. **공간 재사용**: 이웃 `k` 개의 저수지와 합친다(논문은 반경 30 픽셀 안에서 저불일치 수열로 `k = 5`). 이 과정을 `n` 회 반복하면 픽셀이 사실상 `kⁿ·M` 개 후보를 본 효과가 난다(논문 `n = 2`). 이웃이 서로 다른 픽셀이어야 하며, 어느 시점에서는 이웃 후보를 모두 흡수해 더 좋아지지 않는다.
5. 최종 저수지의 표본으로 셰이딩한다. 저수지를 다음 프레임으로 넘긴다.

비용은 `O(nk + M)` 로, 한 픽셀이 본 효과적 후보 수(`kⁿM`)에 비해 훨씬 작다. 논문은 동적 발광 삼각형 11,000 개 장면을 15 ms, 340만 개 장면을 50 ms(1920×1080)에 그렸다고 보고한다(GPU 는 RTX 2080 Ti, 340만 개 장면은 메모리 때문에 Titan RTX).

### 4. 편향: 이웃의 저수지는 다른 분포에서 왔다

이웃 픽셀은 다른 법선·가림 때문에 목표 분포 `p̂`가 다르다. 단순 합치기는 이웃에서는 가능했으나 내 픽셀에서도 기여가 있는 표본을 버리거나(예: 이웃에서 가려졌지만 나에게는 보이는 광원) 과소 가중해 **장면이 어두워진다**. 논문의 해법은 RIS 의 가중 `1/M` 대신 `m(x)` 를 쓰고 `Σ m = 1` 이 되게 하는 것이다(식 (20)~(22)). 실제 알고리즘 6 은 "내 픽셀의 선택 표본에 대해 `p̂_{q_i}(y) > 0` 인 저수지의 `M` 만 더해 `Z` 로 쓰는" 균일 가중이고, 분모에 균형 휴리스틱(MIS)을 쓰는 변형도 있다. 비용은 후보마다 `p̂_{q_i}` 를 한 번씩 다시 평가하는 것이고, 가시성을 포함하면 **그림자 광선이 이웃 수만큼 더** 필요하다.

논문은 두 구현을 병행한다.

| 구분 | 편향(biased) | 비편향(unbiased) |
| --- | --- | --- |
| 이웃 수 `k` | 5 | 3 |
| 공간 반복 `n` | 2 | 1 |
| 픽셀당 평가 저수지 | 4 개 | 1 개 |
| 이웃 거부 | 깊이 차 10% 초과 또는 법선 25° 초과면 거부 | 이 휴리스틱은 편향판 설명에서만 언급됨 |
| 추가 광선 | 없음 | 이웃마다 가시성 광선 |

시간 재사용은 저수지의 `M` 이 무한히 커져 오래된 표본이 과대 가중될 수 있으므로 **이전 프레임 `M` 을 현재의 20 배로 자른다**.

## 직접 확인: 합치기가 어둡게 만들고 알고리즘 6 이 고친다

광원 64 개, 내 픽셀 `a` 는 모든 광원이 보이고, 이웃 `b` 는 64 중 24 개가 가려졌다(기여 0). 둘 다 후보 `M` 개로 저수지를 만들고, `a` 가 둘을 합쳐 최종 추정(진짜 합은 72.43)을 낸다. 3 만 번 평균이다.

| M | `a` 단독 | 이웃과 단순 합치기 | 알고리즘 6(균일 가중) |
| --- | --- | --- | --- |
| 4 | 진짜 값의 0.997 | **0.840** | 0.998 |
| 16 | 0.996 | **0.837** | 0.996 |

단순 합치기는 약 16% 어둡고, 알고리즘 6 은 평균이 맞는다. 이 장난감은 목표를 정확한 기여로 잡아 RIS 의 분산 이득(단독이 균일 샘플링과 같아짐)은 보여 주지 못하며, 비편향 합치기의 표준편차는 `M = 16` 에서 0.42 로 단독의 0.33 보다 오히려 컸다. 즉 편향이 사라진다고 분산이 줄지는 않는다.

## 언제 쓰나

- 광원이 **많고 움직이는** 장면의 1차 히트 직접 조명(수천~수백만 광원). 동적 광원에 대해 갱신 가능한 자료구조가 필요 없다.
- 픽셀 간·프레임 간 **상관이 큰** 장면: 이웃의 기하·재질이 비슷하고 카메라·광원 움직임이 크지 않을 때.
- 디노이저 앞단. 샘플 품질을 올려 주지만 완전히 노이즈 없는 결과는 아니다(논문도 가시성 노이즈가 남는다고 한다). NRD 에 넣을 때는 `hitT` 정의에 주의한다([NRD 입력 계약](/develop-wiki/knowledge/graphics-xr/nrd-reblur-relax-denoiser-inputs/)).

## 주의/비용

- **재사용이 안 되는 곳**: 디스오클루전, 조명 불연속, 기하가 복잡한 곳, 빠르게 움직이는 광원에서는 노이즈 감소가 작다(논문 8.1절).
- **1차 히트에 한정.** 논문의 자료구조는 화면 공간 이미지 버퍼라서 카메라 경로의 첫 정점에서의 직접 조명만 다룬다. 간접광이나 이후 바운스로의 확장은 "미해결" 로 남겼다(후속 연구는 읽지 않음).
- **편향 vs 비용.** 비편향판은 가시성 광선이 늘어 비싸고, 편향판은 이웃 선택 휴리스틱으로 줄이지만 경계에서 어두워진다. 논문은 렌더 시간이 길어지면 비편향 시간 재사용이 편향판을 이긴다고 한다(대략 1초).
- **상태 저장.** 저수지 버퍼를 프레임 간 유지하므로 카메라 컷, 해상도 변경, 모션 벡터 오류에서 리셋이 필요하다.
- **오래된 표본.** `M` 상한(20배) 같은 클램프를 두지 않으면 지연·번짐이 생긴다.
