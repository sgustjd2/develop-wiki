Lossius·Baltazar·de la Hogue, "DBAP – Distance-Based Amplitude Panning"(ICMC 2009)은 Jamoma 의 **2011-04-14 수정판**(식 3~6, 9~10 오류 수정)을 읽었다. VBAP 의 상상의 스피커 처리는 Zotter·Frank 의 Ambisonics 책(Springer 2019, CC BY 4.0) 3.3절을 읽었다. 청취 실험에 의한 정위 정확도 비교 자료는 읽지 않았다. 표의 수치는 내가 직접 계산한 것이다.

## 문제

스피커 여러 대로 "스피커가 없는 방향" 에서 소리가 나게 하려면 각 스피커에 같은 신호를 얼마의 음량으로 보낼지 정해야 한다. 두 가지 질문이 갈린다.

- 청취자가 한가운데(스위트 스폿)에 있고 스피커가 그를 둘러싼다고 **가정할 수 있는가**. 영화관·스튜디오·돔은 가정할 수 있다.
- 가정할 수 없는 곳: 관객이 돌아다니는 전시, 무대 위에 흩어진 스피커, 여러 방에 걸친 설치 작품.

VBAP 는 전자, DBAP 는 후자를 위한 방법이다.

## 해법

### 1. VBAP (Pulkki 1997)

**2차원.** 청취자에서 두 스피커로 향하는 단위 벡터 `l1`, `l2` 를 기저로 보고, 가상 음원 방향 `p` 를 그 선형 결합 `p = g1·l1 + g2·l2` 로 쓴다. 행렬로 쓰면 `g = pᵀ L⁻¹` 이고, 2×2 역행렬은 스피커 배치를 정할 때 한 번만 계산해 둔다.

- 이렇게 구한 이득은 **탄젠트 법칙**(`tan φ / tan φ0 = (g1 − g2)/(g1 + g2)`)을 만족한다고 논문이 부록에서 증명한다. 사인 법칙은 머리가 정면을 볼 때, 탄젠트 법칙은 머리가 음원을 향해 돌 때 더 맞는다고 하며, 둘 다 약 500~600 Hz 이하에서 성립하는 근사라고 한다.
- 음량을 일정하게 하려고 이득을 정규화한다. 이득 제곱합을 상수 C 로 두며(`g1² + g2² = C`), C 는 가상 음원의 음량 조절이다.
- 스피커가 여럿이면 **이웃한 스피커끼리** 쌍을 만들고, 음원 방향에서 음수 이득이 안 나오는 쌍을 고른다. 논문은 실무에서는 "가장 작은 이득이 가장 큰 쌍" 을 고르라고 권하고, 수치 오차로 생긴 작은 음수는 정규화 전에 0 으로 만든다. 쌍들의 활성 호(arc)가 겹치지 않으므로 음원이 움직여도 이득이 연속적으로 바뀐다.

**3차원.** 스피커 세 개의 벡터로 같은 식을 푼다(3×3 역행렬). 가상 음원은 세 스피커가 이루는 **활성 삼각형** 안에만 놓인다. 논문이 정리한 성질:

1. 음원이 스피커 방향과 같으면 그 스피커 하나만 소리 낸다(가장 날카로운 음상).
2. 두 스피커를 잇는 선 위면 그 쌍만 쓰고 셋째 이득은 0 이다.
3. 삼각형 중심이면 세 이득이 같다.

스피커는 청취자와 거의 같은 거리에 있어야 하고, 방이 너무 울리지 않는다고 가정한다. 거리 차이는 지연·이득으로 보정할 수 있다고 한다.

### 2. DBAP (Lossius 외 2009)

청취자 위치를 가정하지 않는다. **모든 스피커가 항상 켜져 있고**, 음원에 가까운 스피커일수록 크게 낸다.

1. 음원과 i번째 스피커의 거리 `d_i`.
2. 세기 일정: 모든 스피커 진폭 제곱합 `Σ v_i² = 1`.
3. 진폭은 거리의 거듭제곱에 반비례: `v_i = k / d_i^a`.
4. 지수 `a` 는 거리가 두 배일 때의 감쇠 R(dB)로 정한다: `a = R / (20 log10 2)`. R = 6 dB 이면 자유 음장의 역거리 법칙(a ≈ 1)이고, 닫힌 공간은 보통 3~5 dB 라고 한다.
5. 정규화 계수: `k = 1 / sqrt(Σ 1/d_i^{2a})`.

보완 장치:

- **공간 블러 r_s**: 음원이 스피커 위에 정확히 오면 0으로 나누게 되고, 그 스피커 하나만 울려 음색·퍼짐이 갑자기 바뀐다. 거리에 `r_s` 를 더해(`d_i = sqrt(dx² + dy² + r_s²)`) 막는다. 너무 크면 선행음 효과로 청취자에게 가까운 스피커 쪽으로 음상이 끌린다고 한다.
- **스피커 볼록 껍질 밖의 음원**: 멀어질수록 모든 스피커 거리 차가 줄어 블러가 커진 것처럼 된다. 그래서 껍질 밖이면 껍질 경계 위의 가장 가까운 점으로 투영해 계산하고, 껍질까지의 거리는 감쇠·공기 흡수·잔향 같은 추가 처리에 쓰라고 한다.
- **스피커 가중치 w_i**: `v_i = k·w_i / d_i^a`. 음원을 특정 방·스피커 무리로 제한하는 데 쓴다.

```ts
type P = [number, number];
// DBAP (수정판 식 1~5, 8). R: 거리 두 배당 감쇠 dB, rs: 공간 블러
function dbap(src: P, speakers: P[], R = 6, rs = 0): number[] {
  const a = R / (20 * Math.log10(2));
  const d = speakers.map(([x, y]) => Math.sqrt((x - src[0]) ** 2 + (y - src[1]) ** 2 + rs * rs));
  const k = 1 / Math.sqrt(d.reduce((s, di) => s + 1 / di ** (2 * a), 0));
  return d.map((di) => k / di ** a);
}
```

**직접 계산.** 4 m 정사각형 모서리에 스피커 4대(앞왼쪽, 앞오른쪽, 뒤오른쪽, 뒤왼쪽), R = 6 dB:

| 음원 위치 | r_s | 이득 (앞L, 앞R, 뒤R, 뒤L) |
| --- | --- | --- |
| 중앙 (0, 0) | 0 | 0.500, 0.500, 0.500, 0.500 |
| (1, 1) | 0 | 0.364, 0.813, 0.364, 0.272 |
| 앞R 근처 (1.9, 1.9) | 0 | 0.037, 0.998, 0.037, 0.026 |
| 앞R 근처 (1.9, 1.9) | 0.5 | 0.130, 0.979, 0.130, 0.093 |

모든 경우 제곱합은 1.000 이었다. 블러를 주면 스피커 바로 옆에서도 다른 스피커가 조금씩 남는다. 같은 방식으로 VBAP 2차원(±30° 스테레오)을 계산해 보면 음원 10°에서 이득 0.883, 0.470 이고, 탄젠트 법칙 양변이 둘 다 0.3054 로 일치했다.

### 3. 3D 배치의 구멍: 상상의 스피커

반구형 배치(바닥에 스피커 없음)에서 VBAP 는 아래쪽 방향에 삼각형이 없다. Zotter·Frank 책은 천저(바로 아래)나 사각형 배치의 가운데에 **상상의 스피커**를 넣어 삼각분할을 완성하는 방법을 정리한다. 그 신호는 버리거나(천저의 경우 지평선 근처 음원은 여전히 수평 스피커로 간다), 이웃 M 대에 `1/√M` 이하로 나눠 섞는다. 이것은 [AllRAD](/develop-wiki/knowledge/graphics-xr/ambisonics-speaker-decoders-maxre-allrad/)에서도 같은 방식으로 쓰인다.

## 언제 쓰나

- **VBAP**: 청취 영역이 스피커로 둘러싸인 중앙이고 배치가 불규칙할 때(5.1, 7.1.4, 돔). 논문이 말하는 대로 주어진 배치에서 음상을 가장 날카롭게 만들고 싶을 때.
- **DBAP**: 관객이 돌아다니거나 청취 위치를 정할 수 없는 공연·전시·설치. 스피커가 원이나 구 위에 있지 않을 때. 계산이 가볍다(행렬 곱).
- 헤드폰 재생이면 둘 다 아니고 [HRTF 바이노럴 렌더링](/develop-wiki/knowledge/graphics-xr/hrtf-binaural-rendering/)이다.

## 주의/비용

- **VBAP 의 음상 폭 변화.** 음원이 스피커 방향에 오면 스피커 하나만, 사이에 오면 둘·셋이 울려 퍼짐과 음색이 위치에 따라 달라진다. DBAP 논문도 같은 문제를 VBAP 에 관한 Pulkki 1999 를 인용해 언급한다. Zotter·Frank 책이 다루는 MDAP(여러 VBAP 음원을 겹침)가 대안이다.
- **VBAP 의 스위트 스폿.** 진폭 패닝은 가상 음원을 활성 영역 밖에 놓을 수 없고, 정위 오차의 최대값은 활성 영역 크기에 비례한다고 논문이 말한다. 넓은 청취 영역에서 정확도가 필요하면 스피커를 더 촘촘히 놓아야 한다.
- **삼각분할의 모호함.** 사각형으로 놓인 스피커는 삼각형 둘로 나누는 방법이 두 가지라 좌우 비대칭이 생길 수 있다(Zotter·Frank 책 그림 3.10). 상상의 스피커로 대칭을 되찾는다.
- **DBAP 는 방향이 아니라 위치를 패닝한다.** 청취자에 따라 같은 음원이 다른 방향에서 들린다. 이것은 결함이 아니라 설계 전제지만, 특정 자리에서 정확한 방향이 필요하면 맞지 않는다.
- **DBAP 의 블러·감쇠 튜닝.** R 은 방의 울림에 따라 다르고(논문은 닫힌 공간 3~5 dB), r_s 는 실험적으로 한계가 있다고만 한다. 둘 다 현장에서 조정할 값이다. 논문의 구현은 블러 계수를 "리그 중심에서 스피커까지 거리의 공분산" 으로 정규화했다고만 적고 식은 싣지 않는다.
- **원 논문의 오류.** DBAP 초판은 식 3~6, 9~10 에 오류가 있어 2011년 수정판이 나왔다. 구현할 때는 수정판을 본다.
