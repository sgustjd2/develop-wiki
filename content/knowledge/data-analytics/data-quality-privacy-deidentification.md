## 개요

- 이 노트는 두 주제를 묶는다. (1) 데이터가 쓸 만한가를 말하는 **품질 특성**, (2) 개인을 알아볼 수 없게 만드는 **법적 개념과 기법**이다.
- 법적 개념(가명정보, 익명으로 보는 정보)과 기술적 모델(k-익명성 등)은 다른 층위다. 기술 모델 하나를 만족한다고 법적 요건을 충족한다는 뜻이 아니다.
- 이 노트는 조문 **내용**을 옮길 뿐 법률 해석이나 자문이 아니다. 실제 적용은 시행령·고시·가이드라인과 전문가 검토가 필요하다.

## 핵심 용어

| 용어 | 영어 | 정의 |
| --- | --- | --- |
| 가명처리 | pseudonymization | 개인정보의 일부를 삭제하거나 일부·전부를 대체하는 등으로 추가 정보 없이는 특정 개인을 알아볼 수 없게 처리하는 것(개인정보 보호법 제2조 1의2호) |
| 가명정보 | pseudonymized information | 개인정보를 가명처리해 원래 상태로 복원하기 위한 추가 정보의 사용·결합 없이는 특정 개인을 알아볼 수 없는 정보(같은 법 제2조 1호 다목) |
| 익명정보 | (법에 정의 조문 없음) | 법 제58조의2 는 시간·비용·기술 등을 합리적으로 고려할 때 다른 정보를 써도 더 이상 개인을 알아볼 수 없는 정보에는 이 법을 적용하지 않는다고 규정 |
| 준식별자 | quasi-identifier | 단독으론 식별 못 해도 외부 정보와 결합하면 개인을 식별할 수 있는 속성 집합(Sweeney 2002) |
| k-익명성 | k-anonymity | 준식별자 값 조합이 테이블에서 최소 k번 나타남(Sweeney 2002 정의 3) |
| 차분 프라이버시 | differential privacy | 이웃 데이터베이스에 대한 출력 분포가 ε(·δ) 안에서 비슷하도록 하는 무작위 알고리즘의 성질(Dwork·Roth) |

## 데이터 품질 — ISO/IEC 25012

- 이 표준은 구조화된 데이터의 품질 모델로 **15개 특성**을 정의하고, 고유(inherent)와 시스템 의존(system-dependent) 두 관점으로 나눈다. 아래 정리는 표준 본문이 아니라 표준의 표를 인용한 2025년 논문의 부록(Table 13)에서 읽었다.

| 분류 | 특성(영어) | 뜻 요약 |
| --- | --- | --- |
| 고유 | 정확성 Accuracy | 속성이 맥락에서 실제 값을 올바르게 나타냄(구문적·의미적) |
| 고유 | 완전성 Completeness | 기대되는 모든 속성·관련 인스턴스에 값이 있음 |
| 고유 | 일관성 Consistency | 모순이 없고 다른 데이터와 부합함 |
| 고유 | 신뢰성 Credibility | 사용자가 참이고 믿을 만하다고 보는 정도(진본성 포함) |
| 고유 | 최신성 Currentness | 맥락에 맞는 시점의 데이터 |
| 고유+시스템 | 접근성 Accessibility | 장애가 있는 사람 등도 접근 가능 |
| 고유+시스템 | 준수성 Compliance | 표준·관례·규정을 따름 |
| 고유+시스템 | 기밀성 Confidentiality | 권한 있는 사용자만 접근·해석 가능 |
| 고유+시스템 | 효율성 Efficiency | 적절한 자원으로 기대 성능으로 처리 가능 |
| 고유+시스템 | 정밀성 Precision | 정확한 값이거나 구분이 가능한 정도 |
| 고유+시스템 | 추적성 Traceability | 접근·변경의 감사 추적이 남음 |
| 고유+시스템 | 이해성 Understandability | 적절한 언어·기호·단위로 읽고 해석 가능 |
| 시스템 의존 | 가용성 Availability | 권한 있는 사용자·응용이 가져올 수 있음 |
| 시스템 의존 | 이식성 Portability | 설치·교체·이동 시 품질이 유지됨 |
| 시스템 의존 | 복구성 Recoverability | 장애 시에도 일정 수준의 운영·품질 유지·복원 |

- 분류(고유 5 / 양쪽 7 / 시스템 3)는 위 논문 표의 가로선 구분을 따랐다. 표준 원문은 유료라 직접 읽지 못했다.
- 결측·이상값 같은 전처리 기법은 특성의 일부(완전성·정확성)를 측정·개선하는 도구다 → [결측값](/develop-wiki/knowledge/data-analytics/missing-values-handling-mechanisms/), [이상값](/develop-wiki/knowledge/data-analytics/outlier-detection-methods/).
- 용어 충돌: "정확도(accuracy)"는 분류 모델 평가 지표로도 쓰인다. 데이터 품질의 정확성과 다른 개념이다.

## 2016 가이드라인의 기법 이름

2016-06-30 관계부처 합동 보도자료(금융위 게시)는 "개인정보 비식별 조치 가이드라인" 발간을 알리며 기법 이름을 5개 든다: 가명처리, 총계처리, 데이터 삭제, 범주화, 데이터 마스킹. 보도자료는 개별 정의를 싣지 않는다. 가이드라인 본문은 읽지 못해 아래 설명은 필자 예시이며 현행 효력도 확인하지 않았다.

| 기법 | 예시(필자) |
| --- | --- |
| 가명처리 | 이름·주민번호를 임의 코드로 대체(복원용 매핑표는 별도 보관) |
| 총계처리 | 개별 값 대신 합계·평균 등 집계값만 제공 |
| 데이터 삭제 | 식별 가능한 컬럼·행 제거 |
| 범주화 | 나이 34 → "30대", 우편번호 5자리 → 앞 3자리(Sweeney 의 generalization 과 같은 계열로 볼 수 있음) |
| 데이터 마스킹 | 전화번호 일부를 `*`로 가림 |

- 같은 보도자료의 4단계 절차: 사전 검토 → 비식별 조치 → 적정성 평가(외부 평가단, 계량 수단으로 k-익명성 활용) → 사후 관리. k=5 를 예로 든다.

## 프라이버시 모델 (원 정의)

- **k-익명성**(Sweeney 2002, *Int. J. Uncertainty, Fuzziness and Knowledge-Based Systems* 10(5), 557–570): 테이블 RT 와 준식별자 QI 에 대해, RT[QI] 의 각 값 조합이 최소 k번 나타나면 k-익명이다. 초록은 "각 개인의 정보가 릴리스에 나온 다른 k−1명 이상과 구별되지 않는다"로 요약한다. 일반화·억제(suppression)로 달성한다. 논문은 정책을 지키지 않으면 k-익명 릴리스에도 재식별 공격이 가능하다고 경고한다.
- **l-다양성**(Machanavajjhala 외, ICDE 2006): k-익명 테이블에서 같은 준식별자 블록의 민감 값이 모두 같으면(동질성 공격), 또는 공격자가 배경지식으로 값을 좁히면 민감 정보가 드러난다. 원리 2는 블록이 민감 속성에 "충분히 대표되는(well-represented)" 값을 ℓ개 이상 가져야 ℓ-다양하다고 한다. 엔트로피 ℓ-다양성(정의 4.1)은 블록의 엔트로피가 log ℓ 이상이어야 한다.
- **t-근접성**(Li·Li·Venkatasubramanian, ICDE 2007): 각 동치류의 민감 속성 분포와 전체 테이블 분포의 거리가 임계값 t 이하여야 한다(정의 2). 분포 거리로 Earth Mover's Distance 를 쓰며, 범주형에서 모든 값 사이 거리를 1 로 두면(equal distance) EMD 가 분포 차이의 절반 합(variational distance)과 같다. 논문은 ℓ-다양성이 못 막는 skewness·similarity 공격을 다룬다.
- **차분 프라이버시**(Dwork 2006 ICALP "Differential privacy"; Dwork·McSherry·Nissim·Smith, TCC 2006): Dwork·Roth(2014) 정의 2.4 — 무작위 알고리즘 M 이 (ε,δ)-차분 프라이버시이면 ∥x−y∥₁≤1 인 모든 x, y 와 모든 출력 집합 S 에 대해 Pr[M(x)∈S] ≤ exp(ε)·Pr[M(y)∈S] + δ. δ=0 이면 ε-차분 프라이버시. 라플라스 메커니즘(정의 3.3)은 f(x)에 Lap(Δf/ε) 잡음을 더하며 ℓ1 민감도 Δf 가 크거나 ε 이 작을수록 잡음이 커진다(ε-차분 프라이버시 보장).

## 직접 계산 (Python 3.15.0, pandas 3.1.1, numpy 2.5.5, seed 고정)

8행 장난감 표(우편번호, 나이, 질병 A~D)를 범주화(우편번호 앞 3자리, 나이는 10살 구간)한 뒤 준식별자 (우편번호, 나이)로 측정했다.

| 지표 | 결과 |
| --- | --- |
| 원본 k | 1 (일부 행이 유일) |
| 범주화 후 k | 2 (동치류 크기 4·2·2) |
| 동치류별 서로 다른 질병 수 | 모두 2 → 구별 ℓ-다양성 2 |
| 동치류 하나(130**, 20대: A,A,B,A)의 엔트로피 기준 유효 ℓ | exp(H)=1.755 → 엔트로피 2-다양성은 아님 |
| t(균등 거리 EMD = 분포 차이 절반합) | 동치류별 0.375, 0.25, 0.625 → 전체 t 는 최대 0.625 |
| 라플라스 잡음 샘플 3개(seed 0, 민감도 1) | ε=1: 0.32, −0.617, −2.502 / ε=0.1: 3.201, −6.17, −25.017 (ε 이 작을수록 크기 10배) |

- 같은 k=2 표라도 구별 ℓ 은 2, 엔트로피 ℓ 은 1.755, t 는 0.625 로 서로 다른 면을 본다. 값은 이 8행 표에 한정된 예시이며 일반 성능이 아니다.

## 언제 쓰나 / 주의

- 품질 특성은 프로젝트 초기에 "어떤 특성이 중요한가"를 정해 측정 규칙으로 바꿀 때 쓴다. 15개 모두를 점검할 필요는 없다.
- 공개·공유용 데이터를 만들 때는 가명처리인지, 익명으로 볼 수 있는 수준인지를 목적에 맞춰 구분한다. 가명정보는 법 적용을 받으며 안전조치·기록·금지의무가 따른다.
- k-익명성은 민감 값 노출(동질성)을 막지 못한다. l-다양성·t-근접성도 완전한 보장은 아니다. 차분 프라이버시는 데이터 공개가 아니라 **질의·알고리즘의 출력**에 대한 성질이다.
- 범주화·삭제를 강하게 할수록 분석 유용성이 떨어진다(프라이버시-유용성 상충).
- 법령은 개정된다. 이 노트의 조문 요약을 근거로 의사결정하지 말고 원문과 전문가 검토를 거친다.
