# 백과사전 본문 작성

리소스 파일(`content/resources/**.md`)의 **본문**, 또는 언어 파일(`content/languages/<id>.md`)을 쓴다. frontmatter 는 건드리지 않는다(언어 파일은 새로 만들 때만).

## 원칙
1. **공식 문서가 1차 출처.** context7 MCP(`resolve-library-id` → `get-library-docs`) 또는 공식 문서 사이트를 직접 읽고 쓴다. 블로그·기억에 의존하지 않는다. 읽은 문서 URL 은 리소스면 frontmatter `docs`, 언어면 `sources` 에 남긴다.
2. **현재 버전 기준.** 설치 명령·API 는 지금 최신 안정 버전 문서로 확인한다. 버전에 따라 다른 부분은 "v5 기준"처럼 명시.
3. **자기 말로 쓴다.** 문서 문장을 번역·복사하지 않는다. 코드 예시는 직접 작성한 최소 예제(20줄 이내), 실제로 동작하는 코드만.
4. **분량:** 본문 60~160줄. 사전처럼 빠르게 훑을 수 있게 표·목록 위주.
5. 확인 못 한 내용은 쓰지 않는다.

## 템플릿 B — 데이터베이스 (backend/database)
```markdown
## 개요
데이터 모델(관계형/문서/키-값/컬럼형/검색/벡터), 저장 방식, 강한 영역.

## 설치·실행
로컬 실행(Docker 한 줄), 공식 클라이언트 CLI 접속.

인덱스 종류, 실행 계획 보는 법.

격리 수준, 원자성 범위, 복제·일관성 모델.

주요 언어 드라이버/ORM (TypeScript, Python, Go, Java 중심) 연결 코드 한 개.

## 운영 팁
백업, 모니터링 지표, 흔한 함정.

## 공식 문서
```
