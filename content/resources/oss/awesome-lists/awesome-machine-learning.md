## 개요
Joseph Misiti 가 관리하는 ML 라이브러리 목록이다. 다른 리스트와 달리 **언어별**(C++, Go, Java, JavaScript, Julia, Python, R, Rust, Scala, Swift 등)로 먼저 나누고, 그 안을 범용 ML, 컴퓨터 비전, NLP, 데이터 분석·시각화로 다시 나눈다. 책·강의·블로그·밋업은 별도 파일로 분리돼 있다. 2026-11 기준 별 약 7.5만, 라이선스 CC0-1.0. 최근 6개월 커밋 49건, 마지막 2026-11-12.

## 이렇게 활용하라
1. **쓰는 언어 섹션으로 간다.** 서비스가 Go·Java·Rust 라면 해당 언어에서 추론·전처리 라이브러리를 찾는다.
2. **Python 은 주요 프레임워크부터 본다.** 이 사이트의 [PyTorch](/develop-wiki/data-ml/ml/pytorch/), [scikit-learn](/develop-wiki/data-ml/ml/scikit-learn/), [JAX](/develop-wiki/data-ml/ml/jax/) 항목과 함께 본다.
3. **courses.md 로 학습 경로를 잡는다.** 강의 링크는 무료 위주다.
4. **LLM 애플리케이션은 다른 자료로 보완한다.** 이 목록은 전통적 ML·딥러닝 라이브러리 중심이라, LLM·에이전트 쪽은 이 사이트의 [AI 에이전트 프레임워크](/develop-wiki/ai/agent-framework/) 와 [Generative AI for Beginners](/develop-wiki/oss/learning-repos/generative-ai-for-beginners/) 를 본다.

## 주의
- 오래된 언어 섹션(Perl, Lua, Common Lisp 등)에는 활동이 멈춘 프로젝트가 많다. README 도 2~3년 커밋이 없으면 deprecated 로 표시해야 한다고 적고 있지만 모두 정리돼 있지는 않다.
- 2026-04 부터 LLM 이 만든 PR 이 많아져, 기여는 관리자에게 메일로 확인을 받는 방식으로 바뀌었다(README 공지). 새 항목 반영이 느릴 수 있다.
- 한국어 번역은 없다.
